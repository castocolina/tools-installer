Target Lua body (the region body between the `-- >>> tools-installer terminal-shell wezterm-keys >>>` and `-- <<< ... <<<` marker lines; two-space indents; the ROWS line is one line per row, in order):

```lua
do
  local wezterm = require "wezterm"
  local act = wezterm.action
  local alias = { CMD = "SUPER", WIN = "SUPER", OPT = "ALT", META = "ALT", CONTROL = "CTRL" }
  local function chord(key, mods)
    local set = {}
    for name in string.gmatch(string.upper(mods or ""), "[^|%s]+") do
      local m = alias[name] or name
      if m ~= "NONE" then set[m] = true end
    end
    local k = key or ""
    if string.match(k, "^%u$") then set.SHIFT = true end
    local names = {}
    for m in pairs(set) do names[#names + 1] = m end
    table.sort(names)
    return string.lower(k) .. "/" .. table.concat(names, "|")
  end
  config.keys = config.keys or {}
  local taken = {}
  for _, entry in ipairs(config.keys) do taken[chord(entry.key, entry.mods)] = true end
  for _, entry in ipairs({
    ROWS
  }) do
    if not taken[chord(entry.key, entry.mods)] then table.insert(config.keys, entry) end
  end
end
```

ROWS, each rendered `    { key = "<key>", mods = "<mods>", action = act.SendString "<send>" },` (four spaces), with `<send>` as Lua `\xNN` escapes for control characters:
- Linux (any non-macOS id): `{ key = "k", mods = "CTRL|SHIFT", action = act.SendString "\x0c" },`
- macOS, in this order: `{ key = "LeftArrow", mods = "OPT", action = act.SendString "\x1bb" },`, `{ key = "RightArrow", mods = "OPT", action = act.SendString "\x1bf" },`, `{ key = "k", mods = "SUPER", action = act.SendString "\x0c" },`

The rows come from `clear_binding(TERMINAL_KEYS["wezterm"], platform_os)`: `("ctrl+shift+k", "\x0c")` -> key `k`, mods `CTRL|SHIFT`; `("cmd+k", "\x0c")` -> key `k`, mods `SUPER`.

`wezterm show-keys --lua` format, verified on WezTerm 20240203-110809-5046fc22 in a scratch HOME (2026-11-20): the default key table is the lines between `  keys = {` and `  key_tables = {`, one entry per line, for example `    { key = 'K', mods = 'CTRL', action = act.SendString 'USER' },`, `    { key = 'k', mods = 'SUPER', action = act.SendString '\f' },`, `    { key = 'LeftArrow', mods = 'ALT', action = act.SendString '\u{1b}b' },`. OPT is shown as ALT, and Ctrl+Shift+K is shown as key `K` with mods `CTRL`. The installer's own rows read back as `act.SendString '\f'` (for `\x0c`), `act.SendString '\u{1b}b'` and `act.SendString '\u{1b}f'`.
