Facts (research, cited): KXMLGUI saves a user's shortcut change for Konsole's session actions in `$XDG_DATA_HOME/kxmlgui5/konsole/sessionui.rc` (`KXMLGUIClient::localXMLFile`; the KF6 library on the host still uses `kxmlgui5`), as `<Action name="clear-history-and-reset" shortcut="..."/>` inside `<ActionProperties>`; the value is `QKeySequence::listToString`, several chords separated by `; `; a cleared shortcut is `shortcut=""`; a shortcut back at its default has no attribute (and a bare element is dropped). KDE rewrites that file and drops comments, so no ownership marker could survive there.

A realistic file for tests:

```xml
<!DOCTYPE gui>
<gui name="konsole" version="1">
 <ActionProperties scheme="Default">
  <Action name="clear-history-and-reset" shortcut=""/>
 </ActionProperties>
</gui>
```

Exact strings (Claude's discretion, fixed here):
- `KONSOLE_CLEAR_REMOVED = "konsole: partial: you removed Ctrl+Shift+K; kept yours"` (the D-09 wording)
- `KONSOLE_CLEAR_STOCK = "Konsole: Ctrl+Shift+K is Konsole's stock Clear Scrollback and Reset (screen and scrollback); left as it is"` (it says what the chord does; it does not claim it sends Ctrl+L, research A5)

Code facts: `sync_terminal_shells` (installer/terminal_shell.py) returns at once on macOS and when zsh is absent; it calls `_sync_konsole(...)` then appends `konsole` to `configured`/`drifted`/`warnings`; `_read_text(path)` returns "" for a missing file and raises `TerminalShellError` (an OSError) for non-UTF-8, a FIFO, a directory or an oversize file; `_xdg_data_home(home, environ)` resolves `$XDG_DATA_HOME`; `sync_message(result, report_changes=...)` builds the Shell parts then the warning part; `TerminalShellResult` is a frozen dataclass constructed only with keywords.
