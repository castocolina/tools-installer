- `requested_by` is a plain `dict[str, str]` typed `Mapping[str, str]` with `field(default_factory=dict)`; no MappingProxyType.
- `closure` is computed by the SAME nested `visit` function, refactored into a local `topo(members: list[Tool]) -> list[Tool]` called twice (once for `runnable`, once for `[t for t in wanted if t.id not in blocked]`). - `Blocked.needs` is captured inside `is_blocked` by replacing the `any(...)` generator with a `next(...)` over the same expression so the first blocking dep id is kept; the boolean result is unchanged.
- Blocked entries are appended in `wanted` (first-seen) order, the same order the warnings use today.
