- Blocked rows (from `Resolution.blocked`) are appended after the closure rows in the resolver's `wanted` order (the order `Resolution.blocked` already has: a selected tool before the dependencies it dragged in, per 20-01); they never run, so their position in execution order is irrelevant; the renderer groups dragged rows under requesters anyway (L-20-05).
