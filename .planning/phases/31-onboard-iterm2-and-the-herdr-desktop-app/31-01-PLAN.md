<objective>
Create the typed ownership union and its two generic mechanisms (31 D-01 to D-04, orchestrator decision 1): `WholeFile` (a file the installer owns outright, proved by the created record plus a fixed GUID) and `OwnedKeys` (two-level keys inside a JSON file the application owns, with per-key state that survives reconfigures), with dispatch at the top of `apply_terminal_keys`, `terminal_keys_pending` and `strip_terminal_keys`, proved on fixture rows only.
