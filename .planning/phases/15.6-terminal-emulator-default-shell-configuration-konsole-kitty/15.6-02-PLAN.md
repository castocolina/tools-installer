<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Installer process → user terminal config | The installer changes files that may contain user-authored shell or Lua configuration. |
| Executable discovery → terminal launch setting | A discovered executable path becomes a terminal-emulator command setting. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-15.6-02 | Tampering | `installer/terminal_shell.py` config writers | high | mitigate | Use paired ownership markers, atomic symlink-preserving writes, and refuse malformed owned regions or unsupported Lua instead of rewriting user content. |
| T-15.6-03 | Elevation | terminal shell selection | high | mitigate | Restrict writes to the user's home on Linux; do not invoke `chsh`, mutate `/etc/passwd`, or use privilege escalation. |
| T-15.6-04 | Spoofing | executable discovery | medium | mitigate | Use the injected `which` result only when zsh is present and pass its resolved path as a data value, never through a shell command. |
| T-15.6-05 | Denial of service | WezTerm Lua configuration | medium | mitigate | Insert only before a recognised return boundary; treat unsupported forms as an explicit no-change failure. |
</threat_model>
