## G-01 — `.zshrc` repair was not `$ZDOTDIR`-aware (code bug)

**Problem:** `sync_terminal_shells` (`installer/terminal_shell.py:408`) called
`ensure_zshrc_template(home / ".zshrc", root)` with a hardcoded
`home / ".zshrc"` instead of `installer.locations.zshrc_path(home, environ)`
— the resolver this codebase already built for exactly this purpose
(`$ZDOTDIR/.zshrc` when `$ZDOTDIR` names an existing directory, else
`~/.zshrc`). `environ` was already a parameter of the function and already
threaded into `omz_root(home, environ)` one line above. On a host with
`$ZDOTDIR` set, this created a spurious `$HOME/.zshrc` containing a fresh
`plugins=(git)` oh-my-zsh template and left the real `$ZDOTDIR/.zshrc`
unrepaired — the same bug class as CR-01, which was fixed for `$ZSH` but left
open for `$ZDOTDIR`. The Policies route (`setup.py::_ZSHRC`) already reached
the correct file, so this was an internal inconsistency within the phase's
own code, not a new design question.

**Fix:**
- `installer/terminal_shell.py`: import `installer.locations.zshrc_path` and
  call `ensure_zshrc_template(zshrc_path(home, environ), root)` instead of
  the hardcoded path.
- `tests/test_terminal_shell.py`: added
  `test_omz_repair_targets_zdotdir_zshrc_when_zdotdir_is_set`, which sets
  `ZDOTDIR` in the test environment to an existing directory and asserts the
  repair writes `$ZDOTDIR/.zshrc` (with the correct, resolved `export ZSH=`
  value and `plugins=(git)`) while `$HOME/.zshrc` is never created. This
  exact scenario was previously untested — the existing 22-test suite never
  set `ZDOTDIR`, which is exactly why the bug shipped.

**Manual verification of the test (per instructions):** the fix was
temporarily set aside via `git stash push -u` on `installer/terminal_shell.py`
only, the new test was re-run and confirmed to **fail** against the unfixed
code (`assert not (tmp_path / ".zshrc").exists()` failed — the spurious file
was created), then the stash was reapplied and dropped to restore the fix.
The test was re-run again afterward and passes.

**Commit:** `856e646` — `fix(15.6): resolve the .zshrc repair target through zshrc_path, not a hardcoded path`

**Fix (`.planning/ROADMAP.md` only, no source code changes):**
