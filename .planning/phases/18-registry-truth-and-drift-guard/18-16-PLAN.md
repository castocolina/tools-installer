<objective>
REG-04 (D-03, D-05), second half, split from plan 18-07 (checker scope_sanity, 2026-10-15). After 18-07 a digest- or checksum-backed install already fetches into staging and is hashed. The no-hash path is still a `curl | tar` shell pipeline with no file on disk. Updates do not read digests, and tarball pins cannot be verified. This plan routes every install through the same staged plain-argv fetch and deletes the shell pipeline. It renders pinned tarball urls from their `version` and verifies them against their `sha256`, and gives the update path the same release resolver.

Purpose: one fetch path with no shell interpolation. Install and update verify against the same sources.
Output: `pinned_url`, the staged no-hash install, the tarball pin check, the update wiring, tests.

The smoke run and the staged swap of the install path are plan 18-09 (wave 4), which builds on this file.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| registry url -> fetch argv | data chooses what is downloaded |
| release download host -> staging file -> ~/.local | untrusted bytes cross into the user's bin/opt dirs, on install and on update |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-18-16 | Tampering | shell interpolation of a registry url in a shell-string pipeline | low | mitigate | the shell pipeline is deleted; every fetch is a plain argv list (Task 1 grep + argv test) |
| T-18-44 | Tampering | an update replaces a verified install with unverified bytes | medium | mitigate | `update_download` checks the same checksum file, pinned sha256 or release digest as install; a mismatch leaves the live install untouched (Task 1 update test) |
| T-18-45 | Tampering | a pinned tarball swapped upstream at the same version | medium | mitigate | the pinned `sha256` is checked on the staged file before extraction; ChecksumMismatch halts the ladder (Task 2 test) |
| T-18-SC | Tampering | npm/pip/cargo installs | high | accept | No package installs; `pyproject.toml` and `uv.lock` unchanged |
</threat_model>
