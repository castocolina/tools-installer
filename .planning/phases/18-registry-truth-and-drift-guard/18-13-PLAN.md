<objective>
REG-02's "verify-registry writes the key as data" and the R11 pin bump (D-02, D-09): the check from plans 18-12 and 18-17 knows which entries passed and which pins are behind; this plan adds the maintainer-only `--write` mode that records that knowledge in registry.toml with a scoped line rewrite guarded by a tomllib re-parse (no new dependency; tomlkit was rejected in D-09), plus `--candidate <id>=<version>` for pins whose upstream is not a GitHub release.

Purpose: a version is bumped only when the new one verifiably works, and `verified` dates mean what they say.
Output: `RegistryEdit`, `RegistryWriteError`, `apply_registry_edits`, the `--write` and `--candidate` flows, tests. The live bump run is plan 18-15; the weekly job never passes `--write` (plan 18-14).
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| verify_registry --write -> installer/registry.toml | an automated writer edits the file every install trusts |
| upstream candidate release -> pinned sha256 | a new pin is derived from upstream bytes |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-18-32 | Tampering | the writer corrupts or reformats the registry | high | mitigate | scoped line rewrite + tomllib semantic guard; any unintended difference aborts before writing; atomic write |
| T-18-33 | Tampering | a pin bumped to an asset that was swapped or renamed | medium | mitigate | the candidate must pass the full check (digest when published, member listing); otherwise the old pin stays (renamed-asset test) |
| T-18-34 | Repudiation | `verified` dates written for entries that never passed | medium | mitigate | dates only for `passed_tools()` (prohibition test); `--write` is explicit and never used by the weekly job |
| T-18-SC | Tampering | npm/pip/cargo installs | high | accept | No package installs; tomlkit rejected (D-09); `pyproject.toml` and `uv.lock` unchanged |
