<objective>
REG-05 (D-06), manager-kind half, split from plan 18-09 (checker scope_sanity, 2026-10-15). Plan 18-09 smokes download kinds in staging, and plan 18-11 smokes app CLIs. Manager kinds (brew, script, native packages, uv-tool, node, sdkman) install through a package manager or a vendor script, so there is no staged binary. D-06 says they are smoked after install, on `shutil.which(tool.cmd)`, and a failure falls through to the next method; Ledger L-18-09 and L-18-14 refine the target for a declared `bin_dir`, and L-18-16 scopes SPEC REG-05's "no linked binary" to installer-created links: a package a failed smoke leaves behind is reported with its removal command, never removed.

Purpose: a manager-installed binary that cannot run on this host never counts as installed.
Output: the manager-kind smoke in `engine.install_tool` and its tests.
</objective>
