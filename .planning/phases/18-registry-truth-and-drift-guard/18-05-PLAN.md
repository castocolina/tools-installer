<objective>
REG-06 (D-11, amended by Ledger L-18-01): `make setup` runs `uv run setup.py`, which puts the project `.venv/bin` (synced with dev dependencies by `make install`) first on PATH, so a dev-only ruff shadows the user's real ruff and reads as installed with an unknown owner (audit D C1). Research proved `uv run --no-dev` alone still resolves `.venv/bin/ruff` in an already-synced venv; `uv run --isolated --no-dev` hides it, leaves the venv untouched and costs about 0.1 s warm. Every setup.py launcher, `install.sh`, and the container e2e harness move to that form; `validate` and `test` keep dev dependencies.

Purpose: the installer sees the host's tools, not its own dev tools.
Output: Makefile launchers, `install.sh`, container harness, a new Makefile test, the install.sh harness test literal, and the living docs that quote the launch command (each doc lands with the launcher it describes).
</objective>
