## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| upstream release bytes -> pinned sha256 in the registry | a new pin is derived from what upstream serves on the run day |
| maintainer gh token -> one networked command | the token raises the API rate limit |
| downloaded binaries -> an execution environment | GUI and CLI binaries are executed by the e2e |
