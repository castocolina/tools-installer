<objective>
REG-07 (D-10): on macOS `/usr/bin/java` and `/usr/bin/git` are shims that exist with no JDK or Command Line Tools, so `is_installed` (first check: `shutil.which(tool.cmd)`) reports both tools present and the installer never offers them. Per D-10 a closed table in installer/status.py maps each stub path to the probe that proves the real tool: `/usr/bin/java` -> `/usr/libexec/java_home` exit 0, `/usr/bin/git` -> `xcode-select -p` exit 0. A stub without the real tool counts as not installed, with a reason the pre-flight audit table shows.

Purpose: a Mac without a JDK or CLT is offered the install instead of being told it is done.
Output: `MACOS_STUBS`, `macos_stub_reason`, `is_installed` keyword seams, `ToolStatus.reason`, the reason in `render_audit`.
</objective>
