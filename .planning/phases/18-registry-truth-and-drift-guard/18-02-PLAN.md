<objective>
REG-08 (D-14): the version parser fabricates versions. `_NAME_PREFIX_BOUNDARY = re.compile(r".*[-\s](?=[vV]?\d)")` accepts an empty name, so `parse_version('-1') == (1, 0, 0, 1)`; lazygit's `version=0.63.1,` and procs' quoted output parse to nothing, so those tools show no installed version.

Purpose: a usage line or flag can never become an "installed version", and two real tools gain a readable version.
Output: a tightened glued-name boundary, one shared token normalizer, and a parametrized fixture table.

Decision recorded (RESEARCH Open Question 6): `a-1` becomes None. The glued-name fallback now requires a name that starts with a letter and has at least two characters, which keeps `jq-1.8.1` (the only glued tool, verified 2026-09-14) and rejects every audit B WR-02 example.
</objective>
