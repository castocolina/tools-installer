<objective>
Close the registry schema (REG-01 D-01, REG-02 D-02, D-03 loader rule). Today `load_tools` keeps every non-structural method key as an opaque param (`model.py` params comprehension), so a typo or a key meant for another kind loads and is silently ignored. This plan adds the closed `METHOD_PARAMS` table, the required structured `verified` TOML date on every `[[tool]]` (seeded from the existing `# Verified` comments, else 2026-10-13 per Ledger L-18-03), and the pinned app/tarball rule (`{ver}` in the url requires `version` + `sha256`).

Purpose: every later Phase 18 plan (data fixes, smoke argv key, pin conversion, verify-registry writer) builds on a loader that rejects unknown keys and requires a verification date.
Output: METHOD_PARAMS + three loader checks in installer/model.py, 90 seeded `verified` keys, rewritten fixture helper, docs.

Out of scope here: the smoke argv key (plan 18-20 adds it; plan 18-09 builds its consumer), the `managed-download`/`drawio-cli` removal (18-06), every audit data fix (18-06, 18-08), pin conversion (18-15).
</objective>
