Decisions recorded for this plan (Claude's discretion):
- Location: `installer/version_status.py`, not `installer/uninstall.py` as RESEARCH Pattern 4 suggests. `version_status` imports `RemovalPlan` and `plan_removal` from `uninstall` at runtime, and the projection compares `Health` values at runtime, so placing it in `uninstall` would create an import cycle. `version_status` already imports `owner_label` and the ownership tables, and it owns `ToolState`, `Health` and the Phase 19 notes (`ADOPTED_NOTE`, `UNPROVEN_NOTE`).
- Gap G1 (RESEARCH): `RemovalPlan.level` and `RemovalPlan.hint` do not exist on `main`. The projection derives the same facts from what the state already carries: proof kind from `ADOPTED_NOTE` in `state.reasons` (adopted), then `state.receipt` (receipt), else the archive layout; the managed hint from `removal_hint(state.ownership, tool.cmd)`. No field is added to `RemovalPlan`.
- `uninstall_group` returns `None` for "not known yet" (no state, or CHECKING) instead of guessing a group. 21-12 keeps the last painted group for such a row so it does not jump sections while `…` shows.
- The managed hint keeps the concrete location: ` — found at {state.ownership.active_path}` when the resolver recorded one, replacing the `which` call `_managed_hint` made (pure, same information). The UI-SPEC "Managed elsewhere, owner known" row is amended in plan check it.1 to document this suffix (`removable.hint` text followed by ` — found at {path}` when the resolver recorded one).
- O1: an installer-owned tool that nothing proves (`removal_hint` is `None`) shows the joined `state.reasons`, which carry `UNPROVEN_NOTE`; no manager is named.
- The functions return plain text. 21-12 builds `Text` from it and sanitizes with `sanitize_log_line` (UI-SPEC: detail text is data, never markup).
- Copy constants beside the Phase 19 notes: `BROKEN_REPAIR_NOTE = "reinstall it from the catalog to repair; nothing to remove here"`, `UNKNOWN_OWNER_NOTE = "owner unknown; nothing here can remove it safely"`, `RECEIPT_PROOF_NOTE = "installed by this installer: receipt matches"`, `LAYOUT_PROOF_NOTE = "installed in userspace — removable here"` (the last one is byte-identical to the `classify_tools` text it replaces).
