## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| registry data -> executors | A registry entry selects a fixed argv or a closed hand-off name; it must never carry a shell, an elevation, `xcode-select`, `softwareupdate` or a launcher | argv, names |
| hand-off table -> user | Display text for the user to run; no code path executes it | text |
| network -> user's home | AWS vendor script (gpg-verified zip), Bruno AppImage (pinned sha256), `gh extension install`, npm `@playwright/mcp@0.0.85` | script, binaries |
| installer -> other agents' config files | `~/.claude.json`, `~/.claude/settings.json`, Cursor, Copilot, OpenCode, Codex files hold the user's own servers | JSON / TOML text |
| ledger file -> revert and preview | The ledger is user-writable JSON; a hand-edited line must not redirect a revert or a preview | file, key path, value |
| harness -> container runtime and host | Three PID-named container targets create and remove their own containers and pulled images | container name, run args |
| orchestrator record -> published evidence | Registry comments and skill rows state what a container run proved | text |
