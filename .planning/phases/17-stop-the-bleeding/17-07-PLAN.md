Hazard H6 (SAFE-05): `_execute_worker` has only try/finally, so an exception ends in a green "Done." and exit 0, and `setup.py:1275,1509` ignore not-attempted rows and update failures. Per D-07 the worker catches `Exception` ahead of its `finally`, keeps finished rows, marks the rest not attempted and records the crash. Per D-08 the failure reaches the exit code through new `Summary` fields shaped like the existing tuple-of-ids outcome fields, folded once by a pure function in session.py.

Purpose: every failed or crashed run says so and exits 1; Phase 20 later maps these tuples onto plan outcomes.
Output: Summary fields + `has_failure` + `fold_run`, worker catch, red status, accumulation, two exit-code lines.

The four other TUI routes (doctor, fix, uninstall, guard) start returning this exit code in plan 17-10, once they can execute at all.
