## Focus-area findings

- **Shim over the symlink.** `atomic_replace_entry` replaces the directory entry and never
  resolves it, so the vendor launcher is never opened for writing. Ownership is the sentinel line
  in the first 4 KiB, read with `O_NOFOLLOW` after an `is_symlink()` check. A foreign regular file
  is reported `kept-foreign` and left byte-for-byte.
- **Model id.** ASCII charset, alphanumeric first character, at most 128 chars, enforced in the
  state decoder, the modal, the engine and `render_shim`. The value is single-quoted in the script.
  An agent path holding `'` is refused. `--list-models` ids are parsed with an even narrower regex
  (`cursor_shim.py:25`).
- **Unit and plist values.** Every ExecStart token and `Environment=` pair is double-quoted after
  rejecting `" \ % $ LF CR`. Env keys are a closed set. HOME/TMPDIR must be absolute, PATH must be
  non-empty, and passthrough values must be printable. A non-quotable F8 value is dropped, never
  written (`schedules.py:895-898`). The plist goes through `plistlib` with the same checks. F17:
  TMPDIR is the platform default, never the caller's (`schedules.py:191-203`).
- **Clean PATH.** Fixed parts only. The caller's PATH is never read.
- **Runner child.** Closed env (`_PASSED_ENV` plus the brew policy, no `SUDO_ASKPASS`), argv
  lists, no shell, its own session, killpg TERM then KILL on timeout and on SIGTERM/SIGINT. The
  update child keeps its vendor update in the group (`run_captured_in_group`).
- **Shared assets.** The sha256 recorded in `state.shared` is the ownership proof. Symlinks and
  unrecorded differing files are refused. Removal happens only under the reconcile lock, with no
  unit on disk by name, and while the run lock can be taken (no run in flight).
- **Receipt re-fingerprinting.** One leaf re-taken under `_WRITE_LOCK`. `_leaf_matches` is
  unchanged.
- **Lock files.** `run.lock`, `schedules.json.lock` and `schedules.reconcile.lock` open with
  `O_RDWR|O_CREAT|O_NOFOLLOW|O_CLOEXEC` and never `O_TRUNC` (`runlock.py:33-36`, runner
  `schedule_runner.py:269`). The holder line is rewritten (`ftruncate`) only while the flock is
  held. Exception: the runner's `<log>.lock` lacks `O_NOFOLLOW` (R2).
- **Log sanitizing.** Runner `_sanitize` on every child-derived text. `parse_log` runs
  `sanitize_log_line`. The view renders `Text` only.
- **No sudo.** None added. Native and OS-package owners are refused before any subprocess.
- **Tests vs. host.** The autouse scratch HOME and the launch allowlist forbid `systemctl` and
  `launchctl`. Engine tests inject `run`/`read_output`. 750 tests passed under that guard.
- **Container harness.** Orchestrator-only, `--systemd=always`, never `--privileged`, every
  in-box call through `ct exec`, and an EXIT trap that removes the container and image.
