| **Quick run command** | `uv run pytest <touched test files> -n 0 --no-cov -q` |
| **Full suite command** | `make validate && make test` |
| **Container (orchestrator only)** | `make e2e` target / `scripts/container-e2e-verify.sh <new subcommand>` added by the phase (systemd-booting target with a user manager per D-26, fallback: direct runner runs, gap recorded) |
| **Estimated runtime** | quick < 60 s per file set; full suite ~2 min locally; container run is long and runs only on the orchestrator |

---

## Sampling Rate

- **After every task commit:** the quick command for the touched test files plus `uv run ruff check installer tests setup.py && uv run pyright` on the touched modules
- **After every plan wave:** `make validate && make test`, then push main and watch CI on both OSes
- **Before `/gsd-verify-work`:** full suite green, then the orchestrator-only container e2e (systemd target), then the real-host UAT (Linux real, macOS if available)
- **Max feedback latency:** 60 seconds per task command
