# Phase 24.2 - Real-host UAT

Eight tests. Tests 1-4 are decisions only you can make; tests 5-8 run on your machine. Run the
host tests in order with no other installer process open. Mark each result and write notes.

## Before you start

- **Launch.** `make setup`. Every launch first repairs installer-owned leftovers (AGENTS.md).
- **Existing timer.** Note whether `systemctl --user list-timers` shows
  `tools-installer-prune-tmp.timer` before the first launch; test 6 checks it is adopted.
- **cursor-agent.** Note what `readlink -f ~/.local/bin/agent` prints; test 7 checks it is unchanged.

### 5. Schedules view

1. `make setup`, press `7`.
   - Expected: `[7] Schedules` is in the tab bar and the whole bar fits; seven rows (tmp cleanup,
     cache cleanup, claude, opencode, copilot, pi, cursor-agent updates). A tool you do not have
     reads `– [n/a]` and its detail says `unavailable: <tool> not installed`.
2. On the claude row press `space` (off), then `space` again (on).
   - Expected: off removes `~/.config/systemd/user/tools-installer-schedule-update-claude.*`;
     on writes them again at mode 0600 (`stat -c %a` prints `600`).
3. Press `e` on cache cleanup, pick another interval and time, `enter`.
   - Expected: the Next cell and `systemctl --user list-timers` agree on the new time.
4. Wait for a slot (or `systemctl --user start tools-installer-schedule-cache-cleanup.service`).
   - Expected: `~/.local/state/tools-installer/schedules.log` has a start line and one result
     line, and the Last cell shows the same result (`✓ HH:MM`, or `skipped: uv cache in use`
     while `make setup` itself is open — that is expected).
