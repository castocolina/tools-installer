## What was built

- Engine in `installer/schedules.py`: `basename_for`/`label_for` (tmp cleanup keeps `tools-installer-prune-tmp` and `com.tools-installer.prune-tmpdir`), `manager_reachable` (the one decision), `_require_available`, `_resolve_uv`, `_ensure_shared_assets`, `runner_argv`, `_apply_linux`, `_apply_macos`, `turn_on`, `turn_off`, `retime`, `set_cursor_model`, `row_state`, `_take_over_competitors`.
- Shared assets: validated as a whole before any write, byte-for-byte copies recorded once in `state.shared` (the sha256 is the ownership proof standing in for SPEC R5's sentinel; the runner keeps its sentinel header), removed only with the last schedule, rolled back on a partial write and on a failed first registration.
- Linux apply follows `linux_daemon_policy._apply`'s two rollback branches (prior registration: restore, reload, re-bootstrap; first apply: disable, restore, unlink the new wants link, reload). Retime rewrites only the `.timer`, cleans the `Persistent=` stamp, and never touches the `.service`, so a running job finishes and the new grid applies from the next slot.
- macOS apply creates the launchd log and its directory before the plist is written and bootstrapped (R1-06); an unrecorded symlink at a unit or plist path is refused before any write (R1-20).
- cursor-agent row: `refresh_shim`/`restore_link` and the saved shim status run inside the `update_state` change; the model list is read before the lock and not at all for an off row (R2-05, R3-10).
- tmp cleanup: the existing units are rewritten in place with one restart (never disable then enable), the legacy wrapper is removed and the decided marker recorded only after registration succeeded, and the competing-timer takeover is a port that returns warnings and never undoes a working registration.

## Known limit for 24.2-13's macOS UAT list (R1-11)

On macOS, `turn_off` and a `retime` of an on row call `launchctl bootout`, which stops a job that is running at that moment; the view's Last cell then reads `failed: interrupted`. Linux spares a running service (disable and restart act on the timer only). This is not testable in the unit suite (no launchd) and must be confirmed on a Mac.
