## Live facts that changed the plan

- `systemd-analyze calendar '*-*-* 23/6:30:00'` → "Invalid argument" (systemd 259), so the slot renderer uses explicit hour lists (D-04).
- The cursor launcher resolves `node` through `realpath "$0"` and sets `CURSOR_INVOKED_AS` from `basename "$0"`, so the shim must exec the absolute target without `exec -a` (D-17).
- cursor-agent's receipt records `~/.local/bin/cursor-agent` as a symlink leaf, so a shim write would trip `broken_drift` (D-19, SPEC R7 amended).
- `update_refusal` refuses pnpm-owned host-setup tools, so a scheduled Pi update would always skip (D-16, SPEC R6 amended).
- The existing prune service runs the checkout script with its own UTC block log, which conflicts with R5/R8 if kept byte-for-byte (D-08, SPEC R3 amended).
- The e2e container has no systemd, which conflicts with R5's "write nothing without a manager" for the e2e acceptance (D-26, SPEC R8 amended).
