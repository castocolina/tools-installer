### `installer/schedules.py` (service, CRUD + file-I/O)

**State file load (schedules.json): copy `installer/settings.py:51-90`.** Path computed at call time (never a module constant: conftest only re-roots `setup.py` attributes, `tests/conftest.py:296-316`), tri-state outcome, warning on damage:
```python
def default_settings_path() -> Path:
    return Path.home() / ".local" / "state" / "tools-installer" / "settings.json"

def load_settings(path: Path) -> LoadedSettings:
    try:
        raw_decoded: object = json.loads(path.read_text(encoding="utf-8"))
    except OSError:
        return LoadedSettings(Settings())
    except ValueError as exc:
        return LoadedSettings(Settings(), warning=(f"Ignoring invalid settings file {path}: {exc}; " ...))
    if not isinstance(raw_decoded, dict):
        return LoadedSettings(Settings())
```
Frozen dataclasses for the row table and the loaded state (`settings.py:35-48`). Saves go through `atomic.atomic_write_text`.

**Validators raise `DaemonScheduleError`** (`installer/daemon.py:63`, an `OSError` subclass) so `run_live` (`ui_common.py:42-56`) surfaces them with no new `except`.

**Injected runners:** every apply/remove takes `run: Runner = run_captured` and `read_output: OutputRunner = systemd_daemon.query_systemctl`, exactly like `setup.py:507-515`:
```python
def _build_daemon_policy(platform, installed, *, which=None, run: Runner = run_captured,
    read_output: OutputRunner = systemd_daemon.query_systemctl, timer_cache=None) -> Policy | None:
```
`which` defaults to `None` and resolves `shutil.which` inside the body (docstring at `setup.py:527-530`), so tests stay deterministic.

**Decided markers:** reuse the `_DECIDED_BEGIN/_END` block pattern only if D-06 keeps the rc marker; otherwise `schedules.json` replaces it (`daemon.py:52-60`, `:347-415`).

## Shared Patterns

- **Error surface:** core raises `OSError` / `DaemonScheduleError` / `CommandError`. Screens call only `run_live` (`ui_common.py:42-56`) and never write their own try/except.
- **Injectable process seams:** `run: Runner = run_captured`, `read_output: OutputRunner = query_systemctl`, `which=None` resolved at call time (`setup.py:507-530`).
- **Atomic writes:** `atomic_write_bytes(path, data, mode=0o644|0o755)` for regular files (`atomic.py:36`). The new entry-replacing primitive is for the shim only.
- **Sentinel ownership:** a sentinel string in every file we own, with refusal on a foreign file (`daemon.py:49, 294-323`).
- **Unit value quoting:** only `systemd_daemon._quote` (`:163-181`). Plists go through `plistlib`.
- **Home paths at call time:** `settings.default_settings_path()` style. No `installer/` module constants built from `Path.home()`.
- **Mutation lock:** refuse first, then `begin_mutation`, a thread worker, a Message, and `end_mutation` in the handler (`wizard_app.py:2666-2720`, `:3136-3167`).
