- **Verification:** `tests/test_receipts.py` stays green unchanged, so no receipt byte moved.
- **Commit:** c0d34cf

**2. [Decision] Whole-file defaults on damage**
- The plan says "defaults for that part". `load_state` returns whole-file defaults, one warning, `damaged=True`, and keeps the original bytes in `schedules.json.damaged`. A non-regular, oversize or unreadable file gives the same warning with no copy (nothing readable to keep).

**3. [Decision] `LastRun.at` is optional in the type, always set by the parser**
- `last_cell` renders the glyph alone for `at=None`; the parser never produces it.

Tests run a real `python -c pass` child (via `sys.executable`) to get a dead pid; the sandbox allowed it. Nothing in this plan starts `systemctl`, `launchctl`, a timer or a container.
