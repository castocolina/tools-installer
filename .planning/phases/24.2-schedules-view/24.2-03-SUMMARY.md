**2. [Rule 2 - Missing critical] `refingerprint_leaf` limited to artifacts of type `leaf`**
- **Found during:** Task 3
- **Issue:** the plan said "find the artifact whose path equals `path`"; replacing a `file` or `link` artifact with a `leaf` would silently weaken that artifact's proof (D-19: never loosen the gate).
- **Fix:** only an artifact with `type == "leaf"` at that path is replaced; any other type returns False. The cursor-agent receipt records the link as a leaf, so the plan's behavior is unchanged.
- **Files modified:** installer/receipts.py
- **Commit:** 4ae51b8
