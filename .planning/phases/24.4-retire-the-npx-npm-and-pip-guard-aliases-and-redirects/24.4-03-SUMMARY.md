# Phase 24.4 Plan 03: Leftover-aware lookups and PATH order Summary

**The leftover-aware lookups moved into `installer/legacy_guard.py` behind one shared `_is_leftover` predicate, every path where the installer runs a binary by name (lookups, schedule runner, install smoke, version probe, ownership probe) now refuses a recognized leftover, and vendor install shells inherit PATH unchanged.**

## Performance

- **Tasks:** 3 of 3
- **Commits:** 3 (`b1d22756`, `5f79dcc4`, `3b795048`)
- **Final gate:** `make validate && make test` exit 0 on each commit's tree (7502 passed, 6 skipped, coverage 96.06%)

## Accomplishments

1. **Task 1 (tracer), `b1d22756`:** moved `PathLookup`, `is_our_shim`, `which_in_path`, `real_binary`, `look_through_shim`, `real_pnpm` verbatim into `installer/legacy_guard.py` (docstrings reworded); `is_our_shim` now returns `_is_leftover(data)`. Repointed all importers. The 23 survivor lookup tests and their helpers (`_lookup_existing`, `_executable`) moved to `tests/test_legacy_guard.py`; `test_rendered_shims_fit_under_the_size_cap` and the writer tests stay in `tests/test_guards.py`. New tests: unremovable read-only-dir pnpm wrapper is never resolved or present, a real pnpm elsewhere is resolved and stable, a leftover removed mid-run still resolves the real binary.
2. **Task 2, `5f79dcc4`:** schedule runner `_SHIM_HEAD_BYTES = 8192` with drift and late-sentinel tests; `engine._manager_smoke_target` skips a declared leftover and looks up through `real_binary` (no `shutil`); `version_status.version_argv` skips leftover candidates, probes the real binary by absolute path behind a leftover PATH hit, or returns `None`; `install_ownership.run_probe` runs a guard-named argv[0] as the real binary or not at all.
3. **Task 3, `3b795048`:** deleted `executors._path_prefix` and `guards.shell_path`; `sh -c` and `bash -c` get the script with no PATH assignment.
