1. Seed in `~/.local/bin`: the marked npx redirect shim and the marked pip, pip3, npm, pnpm hard-block
   shims. Seed an unmarked real `pnpm` stub in `~/real/bin` and an `npx` symlink in `~/volta/bin`, both
   later on PATH.
2. Seed `~/.myshellrc` (LF) with a user line `alias npx='echo user'` and a ban block; `~/.zshrc` (CRLF
   throughout) with a user alias and a ban block; `~/.bashrc` with a user line right before a ban block that
   ends at EOF without a trailing newline.

   `setup.py --guard` and `setup.py --unguard`; snapshot after each.

the blocks. The user alias, the user line plus its newline, the unmarked pnpm and the volta symlink survive
byte for byte. The second run prints no guard line and changes no byte. `make guard` and
`setup.py --guard` are refused.

   `touch /tmp/ti-uat/LEFTOVER_RAN`; `chmod 555 ~/.local/bin`; the real pnpm stub is later on PATH

executes the leftover: the marker file is absent.
