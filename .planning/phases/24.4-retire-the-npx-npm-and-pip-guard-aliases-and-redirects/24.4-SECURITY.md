## Focus-area findings

- **rc block removal keeps user bytes.** The line splitter `[^\n]*\n|[^\n]+` keeps each line's own
  terminator, so CR, CRLF and a missing final newline survive; a marker matches only after one
  trailing CR is ignored. Orphan begin and end lines stay. A non-UTF-8 rc file is skipped, not
  rewritten. The write is atomic, mode-preserving and goes through a dotfiles symlink to its target.
- **Shim deletion never follows a link and re-checks immediately before unlink.** First read:
  `lstat` type + size, then an `O_NOFOLLOW|O_NONBLOCK` descriptor with `fstat` type check. Last
  call before `os.unlink`: `snapshot_matches`, a fresh `O_NOFOLLOW` open comparing device, inode
  and bytes; identical bytes re-prove size <= 8192, strict UTF-8 and the sentinel. The remaining
  window between that re-check and `unlink` is the GUARD-03 residual.
- **Leftover-skipping lookups.** One definition (`legacy_guard._is_leftover`) backs `is_our_shim`,
  `real_binary`, `look_through_shim`, `real_pnpm`, `status`, `engine`, `version_status` and
  `install_ownership`. The standalone runner mirrors it byte for byte, and two tests pin the
  sentinels, the read size and the resolution result to the module.
- **Zero sudo.** No added line in `installer/`, `setup.py`, `Makefile` or `scripts/` in the range
  names `sudo`, `pkexec` or `doas`. The only literal is the existing
  `model.ELEVATION_COMMANDS` refusal set.
- **No host mutation in tests.** See T-24.4-07. `setup.py` resolves `_DEFAULT_BIN_DIR` at import,
  and the autouse fixture re-roots it onto the scratch HOME.
