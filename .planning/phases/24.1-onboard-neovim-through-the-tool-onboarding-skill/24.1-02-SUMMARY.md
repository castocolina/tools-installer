# Phase 24.1 Plan 02: Neovim's EDITOR line as install tuning that yields to you Summary

**Installing neovim writes `export EDITOR=nvim VISUAL=nvim` into `~/.myshellrc` with no question, only when the user's own startup files export neither, through one `user_export` gate that both the writer and the pending-tuning fact consult.**

## What was built

- **Task 1 (df8e422, tracer):** `find_export` in `installer/shellrc.py` (quote-aware word split, statement forms `export`/`typeset -x`/`declare -x`/pure assignments after `;`, `&&`, `||`, `then`, `{`, comment words, terminated installer blocks skipped except the consolidated shellrc block, empty value as unset, last assignment wins). `TweakBundle.yields_to`, the neovim bundle and `user_export` in `installer/tweaks.py` (scan set `path_scan_rc_paths()` plus `~/.zshenv`, capped read with `errors="replace"`, fail closed with a sanitized `Could not read ...` line). The gate in `_tune_shell_init` and `_shell_init_tuning_fact`, `post_install` on the registry row, and the two pinned `test_tweaks` tests plus the 24.1-01 neovim state test fixture repaired.
- **Task 2 (f03fab5):** the scan's edge matrix: `find_export` precision, statement forms, comment words, block adjacency; `user_export` over every startup file, non-UTF-8, missing, FIFO and directory files, oversized and unreadable files, a sanitized file name, a sanitized kept value, multi-assignment export, VISUAL, and the environment ignored.
- **Task 3 (fb13176):** a new bash and a new zsh print `nvim nvim` (and the guard holds with nvim absent), an OS default `EDITOR=/usr/bin/nano` is overridden, the user's `EDITOR=vim` wins, reinstall rewrites in place, a forced RECONFIGURE with the user's editor writes nothing, removal turns off only the neovim block and its record, and an interrupted write leaves `~/.myshellrc` byte-identical with no record.
