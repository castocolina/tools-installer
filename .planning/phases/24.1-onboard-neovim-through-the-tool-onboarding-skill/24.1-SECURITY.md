## Focus-area findings

- **git argv (`run.run_git_isolated`, `clone_nvim_starter`).** Only code constants and a
  `mkdtemp` path. Lists, no shell, `--` before the URL. The child loses the repo and askpass
  variables, runs with no hooks, `autocrlf` off and no prompt, and is bounded at 600 s with
  stdin DEVNULL in a new session.
- **Patch application.** It runs only after `rev-parse HEAD` equals the 40-hex pin.
  `apply --check` then `apply`, in a private temp dir. A failure at any step returns a
  sanitized reason line and removes the temp dir.
- **mkdtemp/move.** The temp dir is a sibling of the target (same filesystem, 0700).
  Symlink refusal and the absent-or-empty re-check run just before `os.rename`, which the kernel
  refuses on a non-empty dir, a link or a file.
- **Stale-dir sweep (F9).** `post_install.py:226-234` removes only `~/.config/.nvim-starter.*`
  entries that are real directories (not links) with mtime older than 2 h (a live run's five
  steps cap at 50 min). `shutil.rmtree` does not follow links. Errors are swallowed. Test
  `test_post_install.py:1688` (fresh and foreign-prefixed dirs kept) passes.
- **Log sanitizing.** Kept and unreadable lines (`tweaks.py:490-503`), the starter's
  `CommandError`/`OSError`/stub reasons (`post_install.py:257`, `:284`, `:287`). See R1 for the
  one unsanitized fragment.
- **Fail-closed rc scan.** An oversize or unreadable regular startup file means no write and no
  strip. Non-regular or missing files are skipped. The read is non-blocking and capped.
- **No sudo.** The phase diff adds none. Native kinds stay MANUAL handoffs.
- **Container harness.** Orchestrator-only, EXIT-trap removal, every test stubs `ct` and
  `exec_tester`. The nvim probes keep XDG dirs outside HOME.
