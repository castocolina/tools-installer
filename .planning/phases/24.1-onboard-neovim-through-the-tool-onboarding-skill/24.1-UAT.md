# Phase 24.1 - Real-host UAT

Eight tests. Tests 1-4 are decisions only you can make; tests 5-8 run on your real host. Run the host
tests in order, one step at a time, with no other installer process open. Mark each result and write
notes in the fields below. The phase closes only after every result is recorded.

## Before you start

- **Launch.** Open the catalog with `make setup`. Every launch first repairs installer-owned leftovers
  (AGENTS.md); that is expected.
- **Copy first.** If `~/.config/nvim` exists, copy it somewhere safe before test 5. Test 5 checks that a
  config of your own is never touched.
- **Shell files.** Note whether any of `~/.zshrc`, `~/.zshenv`, `~/.zprofile`, `~/.profile`,
  `~/.bashrc` or `~/.myshellrc` already sets `EDITOR` or `VISUAL`. Test 6 depends on it.

### 4. Review rule F1/F10

### 5. Bazzite install and removal

1. In the catalog, install Neovim on the user tier.
2. Open a new terminal (no reboot). Run `nvim --version | head -1`.
   - Expected: `NVIM v0.12.6`. The Neovim row shows `✓` on the user tier.
3. If `~/.config/nvim` did not exist (or was empty) before: it now holds the starter, and its
   `init.lua` contains `tools-installer: no language servers`. If it was yours: it is byte-identical to
   your copy, and the install output said `Starter not added: ~/.config/nvim is yours (left as is).`
4. Uninstall Neovim with "delete config too" OFF.
   - Expected: `~/.local/opt/nvim` and `~/.local/bin/nvim` are gone, the receipt is gone, the
     `tweak:neovim` block is gone from `~/.myshellrc`, and `~/.config/nvim` is still there.
5. Install again, then uninstall with "delete config too" ON.
   - Expected: everything from step 4, plus `~/.config/nvim` is gone. (Restore your copy afterwards if
     it was yours.)

### 6. zsh `EDITOR` write, yield and removal

Start with no `EDITOR`/`VISUAL` set in any of your shell files.

1. Install Neovim. Open a new zsh. Run `echo $EDITOR $VISUAL`.
   - Expected: `nvim nvim`.
2. Add `export EDITOR=vim` to `~/.zshrc`. Reinstall Neovim from the catalog.
   - Expected: the output says `Kept your EDITOR (~/.zshrc:<line>; the neovim shell init was not
     written).`, and the `tweak:neovim` block is no longer in `~/.myshellrc`.
3. Open a new zsh. Run `echo $EDITOR`.
   - Expected: `vim`.
4. Remove the line you added in step 2 if you do not want it.

### 7. First interactive nvim run

With the installer's starter in `~/.config/nvim`:

1. Run `nvim`. Accept kickstart's plugin install prompt and wait for it to finish. Quit.
2. Run `nvim some_file.py`. Inside nvim run `:lua print(#vim.lsp.get_clients())`.
   - Expected: `0`. In another terminal, `ps -eo comm | grep -Ei 'pyright|lua_ls|gopls|tsserver|jdtls'`
     prints nothing.
3. Inside nvim run `:!pre-commit run --files %` (in a repo with pre-commit).
   - Expected: pre-commit runs on the file.
4. Inside nvim run `:lsp enable <a server you have installed>` (optional).
   - Expected: that server attaches for this session only.
