## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | pytest >= 8 + pytest-xdist + pytest-cov (`fail_under = 90`), all under the 23.1 sandbox (`tests/sandbox.py`: `git`, `curl`, `uv`, `brew`, `podman`, `docker` are forbidden programs; unit tests use a fake git runner set with `monkeypatch`, fake curl/tar runners, and fake `nvim`/`git`/`uv` executables under `tmp_path`; `sh`, `bash`, `zsh` stay runnable by name) |
| **Config file** | `pyproject.toml` `[tool.pytest.ini_options]`, `tests/conftest.py`, `tests/sandbox.py` |
| **Quick run command** | `uv run pytest -n 0 --no-cov -q <touched test files>` |
| **Full suite command** | `make validate && make test` |
| **Live (read-only)** | `make verify-registry ARGS="--state <scratchpad>/verify-registry-state.json"` (network; never writes the real HOME) |
| **Container (orchestrator only)** | `scripts/container-e2e-verify.sh all --distro fedora|debian|arch` (fedora also runs `nvim-lsp` between pass 1 and pass 2) |
| **Estimated runtime** | quick < 60 s per file set; full suite ~2 min locally; each container run 1-3 h |

---

## Sampling Rate

- **After every task commit:** the task's `<automated>` commands (touched test files, `-n 0 --no-cov`)
- **After every plan wave:** `make validate && make test`, then push main and watch CI on both OSes
- **Before `/gsd-verify-work`:** full suite green, `make verify-registry` with neovim passing on four pairs, then the orchestrator's three sequential container runs (24.1-05 Task 2), never on the host
- **Max feedback latency:** 60 seconds per task command
