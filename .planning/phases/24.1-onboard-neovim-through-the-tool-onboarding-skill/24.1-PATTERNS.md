## Pattern Assignments

### `installer/registry.toml` — neovim entry

**Analog:** herdr (`registry.toml:3049` onward): raw `github_release` asset with no checksum file, verified by the GitHub API sha256 digest (resolve_target). An asset without a digest installs as unverified.
```toml
[[tool.method]]
kind = "github_release"
repo = "herdrdev/herdr"
asset = "herdr-linux-{arch.machine}"
member = "herdr"
[[tool.method]]
kind = "github_release"
repo = "herdrdev/herdr"
asset = "herdr-macos-{arch.machine}"
member = "herdr"
[[tool.method]]
kind = "brew"
...dnf / pacman / apt handoffs
```
Differences for neovim: the asset is a tarball, so use `strip = 1`, `member = "bin/nvim"`, and `{arch.suffix}` (renders `x86_64`/`arm64`, `assets.py:16-23`), not `{arch.machine}`. Copy the comment-block style (dated `# Verified …` research header above `[[tool]]`). Take `owner_probes = ["rpm-ostree", "dnf", "apt", "pacman"]` from alacritty (`:3021`). Full proposed entry: RESEARCH "Pattern 1". Under the provisional decision, drop the `# requires` line.

### `installer/shellrc.py` — `find_export(content, names)` (pure)

**Analog for the block skip:** `rcclean.py:470-481`

```python
def _managed_line_indices(lines: list[str]) -> set[int]:
    blocked: set[int] = set()
    depth_start: int | None = None
    for index, line in enumerate(lines):
        stripped = line.strip()
        if stripped in _MANAGED_BEGINS:
            depth_start = index
        elif stripped in _MANAGED_ENDS and depth_start is not None:
            blocked.update(range(depth_start, index + 1))
            depth_start = None
    return blocked
```
Same walk, except the consolidated block (markers at `shellrc.py:35-36`) is **not** skipped (Pitfall 3: it is user content). Use the regex and last-match-wins rule from RESEARCH Pattern 2. Keep it pure (string in, `(name, value) | None` out). File I/O stays with the caller.

**Analog for reading:** `tweaks.strip_legacy_aliases` (`tweaks.py:342-356`) uses `read_capped(path, cap, follow_symlinks=True)` (`atomic.py:168`) and handles `FileNotFoundError`/`OSError`. **Correction to RESEARCH:** that function decodes strict `utf-8` and reports `UnicodeDecodeError` as unreadable. It does not use `errors="replace"`. The new reader should decode with `errors="replace"` on purpose, so a non-UTF-8 byte cannot hide an export. **Action signature + early-return-with-text analog:** `_set_login_shell` (`:147-156`) checks `shutil.which("chsh") is None` and returns explanation lines. Use the same shape for `shutil.which("git") is None`, returning the reason plus the manual clone commands (provisional decision).
```python
def _set_login_shell(tool, platform, confirm) -> tuple[str, ...]:
    del tool, platform, confirm
    if shutil.which("chsh") is None:
        return _CHSH_ABSENT_EXPLANATION
    return _SET_LOGIN_SHELL_INSTRUCTIONS
```
Flow (RESEARCH Pattern 3): `mkdtemp(dir=~/.config)` → `clone --no-checkout` → `checkout -q -B master <pin>` → `rev-parse HEAD == pin` → `apply --check` → `apply` → re-check absent/empty → `os.rename(tmp, target)` → `finally` rmtree tmp. Skip when the target is a symlink, non-empty, or when `xdg_config_base(home, os.environ) != home/".config"` (`locations.py:57`). Register it in `POST_INSTALL_HOOKS` (`:299-307`). Do **not** add it to `apply_install_tuning` (`:310-333`), so RECONFIGURE never runs it, and do not record it (D-18).
- Crash isolation is already handled: `run_post_install` (`:336-360`) turns an exception into a `"<name> crashed: …"` warning. Expected failures should still return lines, not raise.
- Amend the module docstring (`:12-15`) to say "never spawns an interactive child".

## Shared Patterns

- **Action signature:** `(tool: Tool, platform: Platform, confirm: ConfirmSensitiveAction | None) -> tuple[str, ...] | PostInstallOutput`, with `del` for unused args (`post_install.py:147-156`, `:290-296`).
- **Composition-root injection:** a module-level default plus a `use_*` setter, wired only in `setup.py` (`post_install.py:107-119`, `setup.py:911`).
- **Tests faking injection:** `monkeypatch.setattr(post_install, "_shell_init_sourced_from", ...)` / `use_shell_init_sourcing(...)` (`tests/test_post_install.py:323-329`). Use the same approach for the fake git runner.
- **One gate, two callers:** the yield helper is called from both `_tune_shell_init` and `_shell_init_tuning_fact`, never duplicated.
- **Logged user values** go through `sanitize_log_line`.
