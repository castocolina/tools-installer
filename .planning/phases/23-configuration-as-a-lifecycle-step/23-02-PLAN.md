Decisions recorded for this plan:
- D-07 (locked): guarded splice for every format, no tomlkit/json5. 18 D-09 precedent.
- Module surface (Claude's discretion, consumed by 23-05; keep these names):
  - `SettingsFormat = Literal["json", "jsonc", "toml"]`; `FORMAT_NAMES = {"json": "JSON", "jsonc": "JSONC", "toml": "TOML"}`; `CHANGED_WHILE_WRITING = "changed while being written"`.
  - `class SettingsParseError(ValueError)` built from `(fmt, line, column | None)` with a `fragment` property: `not valid {FORMAT_NAMES[fmt]} (line {line}, column {column})`, or `(line {line})` without a column. JSON/JSONC take `lineno`/`colno` from `json.JSONDecodeError`; TOML parses the message suffix `(at line N, column M)` and maps `(at end of document)` to the last line, no column; non-UTF-8 bytes are line 1, no column.
  - `class SettingsEditRefused(ValueError)` (the guard failed: the splice did not produce exactly the intended document); `class SettingsChanged(OSError)` whose message is `CHANGED_WHILE_WRITING`.
  - `ABSENT` sentinel (a module-level instance of a private `_Absent` class with a `__repr__` of `ABSENT`); `lookup(doc, key_path) -> object` returns `ABSENT` when any part is missing or a parent is not a dict.
  - `parse_settings(text, fmt) -> dict[str, object]`: whitespace-only text is `{}`; a JSON root that is not an object is a parse error at line 1.
  - `strip_jsonc(text) -> str`: same length and same newlines as the input; comment characters and a trailing comma before `}` or `]` become spaces; string-aware with backslash escapes. JSONC parsing is `json.loads(strip_jsonc(text))`, so error positions stay true.
  - `@dataclass(frozen=True) class Inserted: text: str; fragment: str; created_parent: bool`. `insert_key(text, fmt, key_path, value) -> Inserted`: JSON/JSONC accept `key_path` of length 1 or 2 (a 2-part path whose parent is absent inserts the parent member holding the one key and sets `created_parent`); TOML accepts length 1 only. The fragment is inserted right after the target object's `{` as a newline, the indent of that object's first member line (else the parent indent plus two spaces, the root indent being empty), the member `"{key}": {json.dumps(value, ensure_ascii=False)}`, and a comma only when the object already has members. TOML inserts `{key} = {value}` plus a newline before the first line whose stripped form starts with `[`, or at the end (with a leading newline when the file does not end with one). TOML values: `json.dumps` for strings, `true`/`false` for booleans; anything else raises `SettingsEditRefused`.
  - `remove_key(text, fmt, key_path, *, fragment: str | None = None) -> str`: when `fragment` occurs exactly once and contains the located member, delete that occurrence (byte-identical revert); otherwise remove the located member with its following comma (or, when it is the last member, the preceding comma) and the whitespace before it on its line; TOML removes the matching top-level line.
  - `replace_value(text, fmt, key_path, new) -> str` (JSON/JSONC only): replaces the located member's value span with `json.dumps(new)`.
  - Every splice function re-parses its result and raises `SettingsEditRefused` unless the document equals the expected one (deep equality on the parsed dicts).
  - The object scanner is private: it walks an object from its `{`, skipping strings (with escapes), comments (JSONC only) and nested values by balanced braces and brackets, and returns each member's key, key start, value start, value end, and the closing `}` index. It runs only on text that already parsed.
  - `new_file_text(fmt) -> str`: `"{}\n"` for JSON/JSONC, `""` for TOML (23-05 inserts keys into it and records `created_file`).
  - `read_settings(path) -> FileSnapshot | None`: `None` when the path does not exist; otherwise `read_snapshot(Path(os.path.realpath(path)))` (a dotfiles symlink is read through, the real file is what the compare checks).
  - `write_if_unchanged(path, before: FileSnapshot | None, text) -> None`: `before is None` requires the path to still not exist (`os.path.lexists`); otherwise `snapshot_matches(realpath, before)` must hold; on failure raise `SettingsChanged`; then create the parent dir when missing and `atomic_write_text(path, text, mode=before.mode if before else None)`. `delete_if_unchanged(path, before)` applies the same check, then unlinks.
- Snapshot promotion (research Standard Stack): move `_Snapshot`, `_snapshot`, `_snapshot_matches` from shellrc.py to atomic.py as `FileSnapshot`, `read_snapshot`, `snapshot_matches` (same code, same docstrings adjusted); shellrc.py imports them and its private copies are deleted.
