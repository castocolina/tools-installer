<objective>
Agent-host hooks become reversible pairs over one host list. The codegraph hook registers only for present, supported, not-yet-recorded hosts and records them in its receipt; every re-record keeps them; the unregister argv is built from the recorded hosts alone. herdr's pair shape is defined (wired in Phase 24), rtk's hook is deleted, and tealdeer fetches its page cache after install and update.

Purpose: CONF-01 (register half and the unregister builders), CONF-03, CONF-06. Plans 23-06 (drift, re-sync) and 23-07 (removal) build on this.
Output: the rewritten `installer/postinstall.py`, `receipts.record_hooks`, the engine and update dispatch, `run.NotingRunner`, registry and model data, the test sandbox for hosts and the extended real-HOME guard.
</objective>

- `run_postinstall(name, method, runner, hosts: frozenset[str]) -> HookOutcome`: unknown name → `((), None)`; `targets is None` → `pair.register(method, runner, ())`; else `wanted = tuple(h for h in pair.targets if h in hosts)` in map order, `()` → `((), None)` without running anything, otherwise `pair.register(method, runner, wanted)`.
- `register_hooks(tool, method, runner, hosts: frozenset[str] | None = None) -> HookOutcome`: name = `tool.postinstall`; no pair → `((), None)`; `hosts=None` → `present_hosts()` (module-global lookup, so the conftest stub reaches it); for a pair with targets, subtract the receipt's recorded hosts for that name before calling `run_postinstall`; a non-empty result is recorded with `receipts.record_hooks(tool.id, name, registered)`; an `OSError` there appends `hook hosts not recorded: {first line}` to the warning (joined with `; `).
- `hook_method(tool, receipt) -> Method | None`: the tool method whose `receipts.method_key(m) == receipt.method.key`, else the only method of `receipt.method.kind`, else None (the `_recipe_argv` rule, reused by 23-06's sweep).
- `host_labels(hosts) -> str`: catalog ids of the given harness ids, sorted, joined with `, `.
- `_resolve_binary(method, cmd)` is `_resolve_rtk_binary` generalized by command name (brew: `shutil.which(cmd)` then `BREW_BIN_DIRS`; otherwise `bin_dir(_resolve_bin_override(method)) / cmd`). codegraph, herdr and tealdeer all use it.
- codegraph register: one argv, targets comma-joined in map order; success → `(tuple(sorted(wanted)), None)`; `CommandError` → `((), f"codegraph MCP registration failed: {exc}")`. herdr register: one `[bin, "integration", "install", target]` per wanted host; failures collected as `{host}: {first line}` joined with `; `; registered = the hosts that succeeded. tealdeer register: when the runner is a `NotingRunner`, first `runner.note("fetching the tldr page cache — tldr --update")`, then `[bin, "--update"]`; `CommandError` → `((), f"tldr --update failed: {first line}; run it yourself later")` where first line is the first non-empty line of `str(exc)`.
- `unregister_argvs(name, binary, recorded) -> tuple[tuple[str, ...], ...]`: filters `recorded` through the pair's map (unknown ids dropped); nothing left or no unregister → `()`. codegraph: `((binary, "uninstall", "--target", csv, "--location", "global", "--yes", "--keep-cli"),)`, csv in map order. herdr: one `(binary, "integration", "uninstall", target)` per host in map order.
