<objective>
Agent-host hooks register over one host list. The codegraph hook registers only for present, supported, not-yet-recorded hosts and records them in its receipt; every re-record keeps them. rtk's hook is deleted, the catalog `tools` parameter leaves the install and update path, and the test suite stops reading the developer's hosts.

Purpose: CONF-03 and the register half of CONF-01. 23-05 adds the unregister builders, herdr's pair shape and tealdeer's hook on this table; 23-07 (drift, re-sync) and 23-08 (removal) build on both.
Output: the rewritten hook table and dispatch in `installer/postinstall.py`, `receipts.record_hooks`, the engine and update dispatch, the `tools` removal, registry and model data, the test sandbox for hosts and the extended real-HOME guard.
</objective>
