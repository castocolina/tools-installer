When the document is then `{}` and the path is in `created_files`, `delete_if_unchanged`; otherwise `write_if_unchanged` (retry once as above). The setting's entries leave the ledger; an unparsable file keeps them and returns the refusal.
- `revert_agent(agent, *, home, platform_os) -> tuple[FileResult, ...]`: `revert_setting` for each setting that has ledger entries.
- `SettingState = Literal["on", "yours", "off", "drift"]`; `class SettingsUnreadable(OSError)` carrying the reason `{display path} is {fragment}; nothing is written until it parses`. `setting_state(...)`: read or parse failure with ledger entries for the file → raise `SettingsUnreadable`; parse failure without entries → `off`; an entry still holding → `on`; entries but none holding → `drift`; no entries and every key already equal → `yours`; else `off`.
- `file_problem(agent, *, home, platform_os) -> str | None`: the parse fragment (or the both-files sentence) for the review's O7 note; None when readable or missing.
