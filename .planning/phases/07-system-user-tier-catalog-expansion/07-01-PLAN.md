<objective>
Add `zsh` and `oh-my-zsh` as verified `tier="system"` registry entries — the shell and
shell-framework half of ROADMAP Phase 7 — using patterns already proven in this
registry (`podman`'s immutable-Linux-falls-to-brew shape for `zsh`; `sdkman`'s
`detect_path`/`script` shape for `oh-my-zsh`). Reproduce fresh, in a disposable Tier-3
container, the one genuinely novel finding 07-RESEARCH.md surfaced: Oh-My-Zsh's real
`install.sh` does NOT default to a safe unattended install — `KEEP_ZSHRC` stays `no`
even under the script's own non-TTY auto-detection, so a bare `kind="script"` entry
would silently back up and overwrite a user's `.zshrc` on every run. This plan ships
the fix (`env = { RUNZSH = "no", CHSH = "no", KEEP_ZSHRC = "yes" }`) and proves it
against a real filesystem before shipping it, per ONESHOT-RULES Rule 14's own named
example for this exact scenario.

Purpose: REQ-system-tier-shell-container-entries (zsh, oh-my-zsh),

  is NOT safe as a bare `kind="script"` — it is safe only with the three `env` values

  `podman` entry (unchanged) remains the container-runtime story on Linux/Bazzite;
