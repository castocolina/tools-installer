against a real filesystem before shipping it, per ONESHOT-RULES Rule 14's own named

`requires=["zsh"]` alone never drags in — the plan's own Tier-3 container test had

`resolve_dependencies` test over the loaded registry so the fix is proven at the
resolver level too, not only inside a container.
