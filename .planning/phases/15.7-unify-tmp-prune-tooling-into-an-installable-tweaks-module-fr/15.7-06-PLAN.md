## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| filesystem -> Doctor and Policies render paths | a mount probe runs on every ordinary render, including the row-highlight path |
| guidance wording -> user action | a rewritten next step tells the user which control to use; a wrong rewrite sends them to an unrelated action |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-15.7-26 | Denial of Service | probe on the render path | high | mitigate | Every call site wraps the closure in a total guard catching OSError and ValueError, matching the second-layer guard already documented around `last_run_summary`; a failing probe yields no section rather than an exception inside a render |
| T-15.7-27 | Repudiation | `_tui_guidance` prefix capture | high | mitigate | The new rewrite branch is ordered before the existing generic branch and pinned by a test asserting the disk-pressure item is never rewritten into the pnpm-globals sentence |
| T-15.7-28 | Repudiation | a fabricated usage number | medium | mitigate | The detail line reports only a percentage the probe actually produced, falling back to the root free percentage when no temp measurement exists, and is omitted entirely when neither was measured |
| T-15.7-29 | Information Disclosure | Doctor output | low | accept | Only free/used percentages of mounts the user can already inspect with `df`; no paths, no file names |
| T-15.7-SC | Tampering | npm/pip/cargo installs | high | mitigate | Not applicable to this plan: no package-manager install task and no new external dependency |
