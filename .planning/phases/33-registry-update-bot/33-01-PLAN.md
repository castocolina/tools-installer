<objective>
Give `installer/verify_registry.py` the date-only noise flag the registry update bot passes: `--bumps-only` makes a `--write` run write only real pin bumps (and the `verified` date of the tools it bumped), so a bot branch never carries a date-only diff (BOT-04).

Purpose: without the flag `--write` re-dates every passing tool, so every weekly bot branch would be a pile of date edits; plans 33-02 and 33-03 build the CI dispatch and the bot workflow on top of this flag.
