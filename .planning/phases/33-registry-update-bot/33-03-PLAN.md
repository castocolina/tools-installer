## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| repository write access -> `workflow_dispatch` of the bot | A dispatch on any ref makes the bot run that ref's code with the write token, commit on that ref's HEAD and publish a bot branch |
| bot job token -> repository refs | The token has `contents: write` and no push restriction protects the default branch; the protection of the default branch (strict required checks, enforce_admins) is enforced on tokens too |
| upstream release digest -> registry.toml -> bot branch | A poisoned asset would reach the branch only through `verify-registry`'s verified digests |
