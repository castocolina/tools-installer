## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| repository write access -> `workflow_dispatch` of the bot | A dispatch on any ref makes the bot run that ref's code with the write token and publish a bot branch; a dispatch is an owner act |
| bot job token -> repository refs | The token has `contents: write` and the repository sets no push restriction on the default branch, so it could fast-forward an already-green commit there; protection limits which commit can land, not whether the token may push |
| upstream release digest -> registry.toml -> bot branch | A poisoned asset would reach the branch only through `verify-registry`'s verified digests |
