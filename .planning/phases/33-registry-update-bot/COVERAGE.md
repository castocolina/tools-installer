No external API integration: the phase adds one CI workflow, one Python flag, a Dependabot config and a proof runbook; the workflow calls a fixed set of `gh` and `git` verbs (workflow dispatch of `ci.yml`, label create, issue list, edit and create, branch push and delete) and the runbook reads check runs and branch protection, so it wraps no GitHub API surface and exposes no capability subset to decide; the bot's contract is the four actions the SPEC names (publish a branch, upsert one issue, dispatch CI, clean up older bot branches).
