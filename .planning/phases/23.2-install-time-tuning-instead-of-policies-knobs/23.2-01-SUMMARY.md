## Deviations from Plan

### Auto-fixed issues

### Notes and small divergences

1. **Claude JSON file with a comment (Task 3, `test_install_tuning_keeps_a_user_value_as_set_by_you`).** The plan describes a claude file holding a comment. Claude's settings format is `json`, which cannot hold a comment, so the claude half of the test keeps `permissions.defaultMode = "acceptEdits"` plus an unrelated key, and the comment-survival half runs on VS Code (JSONC). The copilot comment survival is pinned in Task 2.
2. **Key position is not write order.** The text splice puts a new key right after the opening brace, so a document's key order is the reverse of the write order. `test_install_tuning_writes_exactly_each_agents_keys` therefore asserts the set of top-level names plus the ledger order (which is the fixed `setting_keys` write order), not the document order. `test_install_tuning_keeps_utf8_comments_byte_for_byte` asserts the head up to `{` and the whole tail are byte-identical, since the new keys land between them.
3. **Phase 23 ledger fixture.** `test_tuning_removal_reverts_a_phase_23_policies_ledger_entry` writes the fixture with `apply_setting("codex", "auto-approve", ...)`, the same call the Phase 23 `agent:codex:auto-approve` row makes, rather than hand-building a ledger JSON.
4. **Run-option agent lists now include copilot.** `AGENT_OPTION_IDS` and `ATTRIBUTION_IDS` derive from `CONFIG_AGENTS`, so they gain `copilot`. No copilot registry row exists until 23.2-04, so no run option shows it and the existing question-text tests still pass; 23.2-08 deletes these tuples with the run options. 23.2-04 should remember that a copilot row would otherwise trigger the old run options until 23.2-08 lands.
5. **Private access in tests.** The removal and copilot tests call `app._after_removal` / `app._revert_settings` with `# pyright: ignore[reportPrivateUsage]`, the pattern tests/test_daemon.py and tests/test_catalog_tui.py already use. No `noqa`/`type: ignore`/`pyright: ignore`/`nosec` was added under `installer/` or `setup.py`.
