# Phase 23.2 Plan 02: Silent-step indicator with a 10 s timestamped heartbeat and ASCII fallback Summary

**A silent install step shows a live one-line spinner under the run log from 2 s, refreshed every second, and appends a timestamped `still running (Ns)` line every 10 s, with an ASCII spinner on non-UTF-8 streams**

## Performance

- **Duration:** ~21 min (proxy, see frontmatter)
- **Started:** 2026-11-07T21:17:47-03:00 (proxy: brief file timestamp)
- **Completed:** 2026-11-07
- **Tasks:** 2 of 2

## Accomplishments

- The static `-- still running; waiting for output --` line and its constant are removed from the screen and its tests (SPEC R10).
- A `#execute-silence` `Static` sits directly under `#execute-log`; hidden until 2 s of silence, refreshed by a 1 s tick while showing, truncated by CSS to the widget width.
- Heartbeats are transient `InstallLogLine`s written through the existing sanitized path, gated by the silence generation and a per-silence counter, at 10 s, 20 s, and so on, measured from the last real output.
- The silence check keeps exactly one pending timer; an open prompt and the run's end leave none pending (review R1-03 pinned from recorded `set_timer` delays).
- `ExecuteInputs` gains `wall_clock` (default `time.time`) and `ascii_spinner` (default False); `wants_ascii_spinner` decides from the encoding; `setup.py` passes `sys.__stderr__`'s encoding.
- `.claude/architecture.md` Phase 15.2 paragraph describes the tick, heartbeat and ASCII fallback; the docs pin moves to `still running`.

## Decisions Made

- Heartbeat text `HH:MM:SS <tool> still running (Ns)` inside the `tool │` prefix (plan, RESEARCH Q2).
- The indicator truncates by CSS (`text-wrap: nowrap`, `text-overflow: ellipsis`); Textual 8.2.7 supports both properties, so no width arithmetic in Python.
- While a prompt is open, `_check_output_silence` hides and returns without re-arming, so no silence timer is pending during a prompt (must-have from R1-03). The close branch re-arms at `SILENCE_SECONDS` and restarts the window.
- The encoding rule is `codecs.lookup(encoding).name != "utf-8"`, with `None` and unknown names treated as non-UTF-8.

### Design interpretations

**3. [Design] No silence re-arm while a prompt is open**
- **Plan text:** the no-in-flight and prompt branch "hides and re-arms at `SILENCE_SECONDS` (as today)".
- **Why not followed literally:** the must-have "no silence timer is pending while a prompt is open" forbids a re-arm during the prompt.
- **Implemented:** hide and return; the close branch re-arms at `SILENCE_SECONDS`. The no-in-flight branch still re-arms at `SILENCE_SECONDS`, as before.

**4. [Design] CSS truncation instead of Python width arithmetic**
- Textual 8.2.7's `text-wrap: nowrap` and `text-overflow: ellipsis` give the required single truncated line; less code than hand-measuring cell widths.

### Added test

**5. [Scope] `test_silence_empty_step_shows_indicator_from_2s_and_heartbeats_at_10s`**
- The must-have "Empty R10" had no dedicated test in the plan. The step's only output is its opening `-- trying cargo --` line, so the tool is established and the indicator and heartbeats run from that line. A step that prints nothing at all still shows nothing, per D-08; `test_install_emitting_nothing_never_shows_an_indicator` still pins that.
