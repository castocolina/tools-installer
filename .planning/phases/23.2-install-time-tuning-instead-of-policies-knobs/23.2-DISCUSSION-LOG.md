## Live facts that changed the plan

- **Linux casks do not resolve.** `resolve.py:68-70` allows `cask` only on macOS with brew, and the Linux vscode cask is ownership-only. The SPEC Background was amended (D-20), and copilot installs on Linux through `@github/copilot` via pnpm.
- **Oh-My-Zsh has no per-tool removal plan.** `registry.toml:620-624` has no `paths`/`remove`, and `_after_removal` has no OMZ branch. SPEC R4's removal acceptance was amended to the full-uninstall sweep (D-12).
- **pnpm refuses global work off PATH.** `pnpm bin -g` fails when its global bin dir is not on PATH, so F-1 needs the dir on the process PATH, not only an absolute pnpm (D-24).
- **codegraph's copilot target id is `copilot-cli`, and graphify supports `--platform copilot`.** Recorded for Backlog 999.12.
- **copilot reads `settings.json` as JSONC** (it accepts a comment and strips it on rewrite), so the format is `jsonc` (D-21).
