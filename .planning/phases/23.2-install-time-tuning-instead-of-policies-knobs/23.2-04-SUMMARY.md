## Deviations from Plan

### Auto-fixed issues

**1. [Rule 2 - Missing critical functionality] The revert probe treated a restored CLI default as a leftover**
- **Found during:** Task 3
- **Issue:** cursor-agent's tuning replaces a CLI-default value, and its revert restores that default (`entry.replaced_default` in `agent_settings`) instead of removing the key. A probe that required every key `ABSENT` would fail a correct uninstall in the container.
- **Fix:** the revert probe counts a key as gone when it is absent or equals its `cli_default`. Added `test_settings_probe_revert_accepts_a_key_restored_to_the_cli_default` (one test beyond the plan's list).
- **Files modified:** scripts/container-e2e-verify.sh, tests/test_container_e2e_receipts.py
- **Commit:** eae570b

**2. [Rule 3 - Blocking] A PATH prepend in the probe tripped the shell-script PATH classifier**
- **Found during:** Task 3 (`make test`, `tests/test_shell_scripts_path.py::test_no_unclassified_accumulating_path_line_in_any_shell_script`)
- **Issue:** my first draft exported `PATH` inside the probe command.
- **Fix:** removed it. The installed probe searches `~/.local/bin`, `~/.opencode/bin` and `PATH` through `shutil.which(path=...)` in Python, and `copilot --version` runs the absolute `~/.local/bin/copilot` link (stricter: it proves our link works). The classifier table was not touched.
- **Commit:** eae570b

### Notes

1. The harness tests build a minimal PATH (a symlink to bash only) so a host `code`, `opencode` or `cursor-agent` can never be picked up as an extra tuned agent.
2. Task 1's `test_copilot_install_writes_its_tuning_keys` passes `present=lambda tool: False` and fakes `download.install_download`; no network, no real copilot, no container was run.
3. The real container e2e (`make e2e`) was not run, per the brief; 23.2-08's phase gate runs it. Untested until then: the exact tester-shell PATH (`~/.local/bin` is set by `write_tester_path`, so `copilot`, `claude` and `codex` links are found), that vscode's `code` is installed in the container (if it is, its keys are checked and must revert too), and that the tarball's single root member is `copilot` (RESEARCH recorded it from a download; not re-downloaded here).
