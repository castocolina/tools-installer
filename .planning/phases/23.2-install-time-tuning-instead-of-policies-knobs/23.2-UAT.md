## Findings

None.

**Observations:**

- **O-1 ASCII spinner is not reached under `LANG=C LC_ALL=C`.** Python's UTF-8 mode (PEP 540)
  makes `sys.__stderr__.encoding` `utf-8` in the C locale, so `wants_ascii_spinner` answers False
  and Braille frames show (the TUI's own box characters are UTF-8 there too). The ASCII frames
  only show with a truly non-UTF-8 stderr (`PYTHONUTF8=0 PYTHONCOERCECLOCALE=0`, or a legacy codec
  locale), and the rest of the TUI is then escaped `\uXXXX`. Consistent with the D-17 rule
  (stream encoding decides). `installer/execute_screen.py:319` `wants_ascii_spinner`,
  `setup.py:1187-1195`. Low.
- **O-2 Indicator and heartbeat clock restart at each output line.** After real output the elapsed
  value restarts at 0 and the heartbeats count `10s, 20s ...` again (the silence is measured from the
  last output, per D-16). The log therefore shows `(10s) .. (40s)` and later `(10s) ..` in one row.
  By design; recorded because it can look like a reset.
- **O-3 Child stdout of the fake pnpm is not in the run log.** `FAKE-PNPM argv:` lines never reached
  the sampled TUI log (the node executor captures pnpm's output through the runner); the argv proof
  is the fake's own `~/fake-pnpm.log`.
- **O-4 Fake pnpm cannot finish the row.** Test 7 ends `failed` at the puppeteer smoke only because
  the fake installs no package. The `done` ending is covered by the unit tests, not this UAT.
- **O-5 Network.** Three claude install attempts failed on TLS EOF at ~10 s (host network, not the
  product); a retry passed.
- **O-6 The absent-pnpm message is not reachable in the TUI.** With pnpm absent, the dependency pass
  plans `pnpm will install`, so only the executor-level check (above) exercises the message.
  Likewise the "installed at ... but is not on this shell's PATH" message only shows when the
  session PATH repair did not run for the row.
- **O-7 At 80x20 the first lines of an agent settings block scroll out of the summary.** After the
  claude install the visible summary starts at `wrote attribution.commit`; the heading,
  `claude — ~/.claude/settings.json:` and the first two `wrote` lines are above the fold. At 34 rows
  the whole block shows. `PageUp`/`Home` did not scroll the summary pane (`Tab` moved focus to the
  run log, which scrolled). codex's two keys and copilot's two keys fit. Likely
  `installer/execute_screen.py` summary region. Low.
- **O-8 claude reads `owner unknown` after the native installer** (`the active binary at
  ~/.local/share/claude/versions/2.1.319 is not attributable to any candidate`), while the Uninstall
  view says `installed by this installer: receipt matches`. Not a 23.2 area; recorded for triage.
- **O-9 Harness artifacts.** `PATH audit: /home/linuxbrew/.linuxbrew/bin duplicated on PATH` comes
  from `brew shellenv` in `.bash_profile` plus the login PATH, and the `PATH order warning` that names
  `/home/tester/fakebin/pnpm` comes from the UAT's fake setup. Neither is product behaviour.
