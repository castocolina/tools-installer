## Focus-area findings

- **Settings writes never overwrite user values, revert byte-identically.** Absent-only
  insert plus `set_by_you` for any other value (T-23.2-01); `cursor-agent` is the one
  deliberate exception, replacing only a value equal to the CLI's own default and restoring it
  on revert (`:697-702`, `:816-818`). Round trips: `test_agent_settings.py:50`, `:355`;
  blank files `:477` (b"", b"\n", b"  \n\n") pass.
- **COPILOT_HOME changes fail closed.** Relative or empty value falls back to `~/.copilot`
  (`agent_env.py:42-43`); a changed absolute value makes the recorded file
  `NOT_A_SETTINGS_FILE`, the file stays byte-identical and the ledger entries stay
  (`test_agent_settings.py:1184`).
- **copilot github_release.** Checksum mandatory and compared before any extraction;
  asset, member and checksum name come from the registry templates, not from the release;
  the extracted member must resolve inside the staged tree and be a regular file; link name
  must be a single name; the staged binary is smoke-run before the swap.
- **fnm/volta.** fnm's vendor rc writer is skipped (`--skip-shell`). volta passes no flag; its
  vendor `setup` writes `export` lines only (verified by reading upstream, registry comment
  `registry.toml:2225-2228`), and the installer's own volta block is `command -v` guarded and
  exports only (`tweaks.py:100-105`). The volta claim rests on upstream behaviour and is not
  test-pinned (see R3).
- **PATH repair.** Never reorders a working PATH, never counts the installer's shim, only a
  registry-declared directory, process environment only.
- **Shell-init record.** Comment-only block, written once per id (`tweaks.py:414-418`),
  `read_record` honours only a closed block, per-tool removal calls `forget_shell_init`,
  full uninstall `clear_shell_init_record`; a non-UTF-8 rc is refused, not rewritten (C-04).
- **Zero sudo / chsh.** Confirmed by grep and `test_app.py:6692`.
- **Tests never touch the real HOME.** `tests/conftest.py` autouse `sandboxed_home`,
  `no_shell_location_env`, session `real_home_untouched`; `COPILOT_HOME` joins
  `CLEARED_ENV_NAMES` (`tests/sandbox.py:748`, `tests/test_sandbox.py:125-126`). The 23.1
  sandbox was only narrowed by that one name (commit `a98657b`): no allowlist widened. The
  run of the suites above left no change under the real HOME (session guard passed).
