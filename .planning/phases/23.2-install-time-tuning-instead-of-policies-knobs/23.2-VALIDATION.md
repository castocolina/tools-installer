## Sampling Rate

- **After every task commit:** the touched-module quick command named in the task's `<automated>` verify
- **After every plan wave:** `make validate && make test`, then push and watch CI on both OSes
- **Before `/gsd-verify-work`:** full suite green and a container `make e2e` pass (copilot install, tune, remove)
- **Max feedback latency:** 60 seconds per task command
