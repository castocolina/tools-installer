### `installer/post_install.py` (service, request-response)

**Analog:** same file. Action signature and table (`:44-45`, `:193-213`):
```python
PostInstallAction = Callable[[Tool, Platform, ConfirmSensitiveAction | None], tuple[str, ...]]

POST_INSTALL_HOOKS: dict[str, PostInstallAction] = {
    "set_login_shell": _set_login_shell,
    "source_shell_init": _source_shell_init,
    "set_omz_theme": _set_omz_theme,
    "show_lean_tips": _show_lean_tips,
}

def run_post_install(tool, platform, confirm=None) -> tuple[str, ...]:
    lines: list[str] = []
    for name in tool.post_install:
        action = POST_INSTALL_HOOKS.get(name)
        if action is None:
            continue
        lines.extend(action(tool, platform, confirm))
    return tuple(lines)
```
Change: actions may return `tuple[str, ...]` or `PostInstallOutput(lines, settings)` (frozen dataclass, RESEARCH "Code Examples"); `run_post_install` merges both. Keep line-returning actions untouched.

**`set_omz_plugins` core** (copy the root/zshrc lookup from `_set_omz_theme` `:157-181`):
```python
home = Path.home()
root = omz_root(home, os.environ)
if root is None:
    return ()
zshrc = zshrc_path(home, os.environ)
myshellrc = home / ".myshellrc"
ensure_zshrc_template(zshrc, root)
```
then `write_plugins(zshrc, myshellrc, root=root)`. Catch `OmzPluginsError` (an `OSError`) and return a line, never crash (RESEARCH anchors R4).

**Sensitive removal (D-13):** `_set_login_shell` becomes `if shutil.which("chsh") is None: return _CHSH_ABSENT_EXPLANATION` then `return _SET_LOGIN_SHELL_INSTRUCTIONS` (drop the `confirm` gate). `_source_shell_init`: drop `confirm is None or not confirm(...)` from the guard, keep `tweak_policy(bundle, rc_path=home/".myshellrc", ensure_sourced_from=lambda: _shell_init_sourced_from()).apply()`. `SENSITIVE_PROMPTS = {}`; `model.SENSITIVE_POST_INSTALL_ACTIONS = ()` (`model.py:132`, `tests/test_model.py:1907`, `tests/test_post_install.py:197-201,:305` rewritten).

## Shared Patterns

### Write only absent keys, ledger the writes
**Source:** `installer/agent_settings.py:644-741`. Apply to every tuning write (install, RECONFIGURE). Single writer; `skip_recorded=True` only for RECONFIGURE.

### Inject environment at the composition root
**Source:** `omz_root(home, os.environ)` in `post_install.py:_set_omz_theme`. Apply to copilot `COPILOT_HOME`, `ascii_spinner`, wall clock. Callees never read `os.environ` (exception: actions in `post_install.py` already do, as `_set_omz_theme`).

### Isolation of post-install crashes
**Source:** `engine.py:383-393`
```python
try:
    return run_post_install(tool, platform, confirm), None
except Exception as exc:  # noqa: BLE001 -- isolation boundary, see design_decisions
    return (), f"post-install actions crashed: {exc}"
```
Both dispatch sites (`engine.py:226-241` `refuses_existing`, `:329-331` success) must carry the new `settings`. `InstallOutcome` has a hand-written `__init__`: new field needs the field, the `__init__` arg, and `object.__setattr__` (`:68-130`). Not dispatched on `ALREADY_INSTALLED` `:199-201` (RECONFIGURE is that route).

### ConfigStep pending pattern
**Source:** `version_status._hook_fact :668-689`. Apply to the tuning fact, OMZ and shell-init pending.
