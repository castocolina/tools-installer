## Accomplishments

- `status.present_bin_dir(tool)` is the single declared-`bin_dir` hit rule; `is_installed` calls it, so presence and the PATH repair answer alike
- `execute_plan` puts a SKIP or done tool's present bin dir on the process PATH when `shutil.which` finds no command, and never reorders a PATH that already finds the tool
- `_node` names the declared pnpm bin dir and says to open a new terminal or `source ~/.myshellrc` when pnpm is present there but off PATH; an absent pnpm keeps today's message byte for byte
- `PNPM_BIN_DIRS` holds the probed dirs and a test pins it to the shipped pnpm registry entry

## Decisions Made

- `present_bin_dir` returns the command file's parent directory, so `is_installed`'s existing answers do not change.
- The PATH repair applies only to SKIP and done rows, and only when PATH does not already find the command (threat T-23.2-20 mitigation, pinned by `test_path_repair_never_reorders_a_path_that_already_finds_the_tool`).
- `_node` probes the declared pnpm homes through a module constant, because the executor has no catalog. A test pins the constant to the registry so the two cannot drift.
- `_pnpm_left_behind` checks that the candidate is a regular file with the execute bit inside each declared dir. It does not run pnpm.
