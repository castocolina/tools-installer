## Trust Boundaries

|----------|-------------|
| Uninstall review -> perform_uninstall config deletion | The decision is built by the UI; deletion re-checks it against the registry |
| CLI uninstall -> user config | The CLI path must never delete config |

| T-22-SC | Tampering | npm/pip/cargo installs | high | accept | This plan installs no package |
