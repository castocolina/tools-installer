## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| receipt JSON (user-writable) -> deletion | a receipt names paths the remover may delete |
| preview -> deletion | files can change between the confirm prompt and the delete |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-19-28 | Tampering / Elevation of Privilege | a tampered receipt naming `~/.ssh/id_ed25519` or another user file | critical | mitigate | delete only receipt ∩ `artifact_paths` of the tool's own methods of the receipt's kind; decoy test (Task 1) |
| T-19-29 | Tampering | a file swapped in place between preview and delete (size/mtime restored) | high | mitigate | deletion-time `plan_removal(verify=True)` re-hash (Task 2) |
| T-19-30 | Tampering | a corrupt receipt silently downgraded to the layout proof | medium | mitigate | an existing-but-unreadable receipt proves nothing (Task 1) |
| T-19-31 | Repudiation | a receipt deleted while its file still exists | low | mitigate | delete the receipt only after every proven path is gone (Task 2) |
| T-19-SC | Tampering | npm/pip/cargo installs | high | accept | No package installs; `pyproject.toml` and `uv.lock` unchanged |
