<objective>
Gap closure, data safety first: make the receipt module's proof exact and fail closed. A directory artifact gets an identity check (G2), the reader keeps only what each artifact type uses (G18), a malformed path can no longer crash a pass or a removal (G5), and the re-hash memo can no longer vouch for the wrong digest (G6).

Purpose: today a `dir` artifact is "proven" by existing, so a stale receipt authorizes `rmtree` of a user's re-installed `~/Applications/<App>.app`; a JSON-escaped NUL path raises `ValueError` from `lstat` and aborts refresh/uninstall; and a memo hit keyed without the digest can report a mismatching file as matching.
Output: `installer/receipts.py` changes plus their tests; one regression test through `plan_removal` and one through the refresh pass.
</objective>
