Implement in installer/receipts.py (D-08, "jev: TypeSafe 0.93"):
- `fingerprint(path, kind)`: use `os.lstat`. "file": `stat.S_ISREG` required, record `sha256_file(path)`, `st_size`, `st_mtime_ns`. "link": `path.is_symlink()` required, record `os.readlink(path)`. - `matches(artifact, *, rehash=False) -> bool`: "link" -> `is_symlink()` and `os.readlink == target`; "dir" -> as above; "file" -> lstat regular file; when `rehash` is False and size and mtime_ns equal the record, True without hashing; otherwise hash. Any OSError -> False.
- `drifted(receipt, *, rehash=False) -> tuple[ReceiptArtifact, ...]`: the artifacts that do not match, in receipt order.
