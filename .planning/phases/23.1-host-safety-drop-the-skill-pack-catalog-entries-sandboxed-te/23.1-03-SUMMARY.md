**npx redirect shim translates -y/-p/--package/--package= for pnpm dlx and refuses every other option with exit 127 before pnpm runs; the interactive alias block drops npx and an old block can be rewritten**

## Accomplishments

- `npx -y -p @opengsd/gsd-core gsd-mcp-server` now reaches pnpm as `dlx --package=@opengsd/gsd-core gsd-mcp-server`, so pnpm runs the named bin and not the package's default bin (the root cause of HOST-02).
- Every option npx has that the translator cannot honour (`-c`, `--call`, `--no`, `--no-install`, `-w`, `--workspace`, `--frobnicate`, a bare `--`, a bare `-`) prints one UI-SPEC stderr line and exits 127; pnpm is never invoked.
- `npx` with no command (or only `-y`) prints the usage line; `-p`/`--package` without a value and `--package=` with an empty value print the needs-a-package line. None of these run pnpm.
- Command arguments, including spaces, quotes and `$`, pass through byte for byte; a `-p` after the command reaches the command unchanged.
- The interactive guard block has no `alias npx=` line, so an interactive `npx` resolves to the translating PATH shim (or to a real npx earlier on PATH, which parses its own flags).
- `rewrite_outdated_ban_aliases(rc_paths)` replaces a well-formed old npx-alias block through `write_ban_aliases`, leaves every other byte alone, never adds a block, and reports `ok` or `warn` per file without raising. 23.1-09 wires it into the launch repair.

## Files Created/Modified

- `installer/guards.py` - `_NPX_TRANSLATE` (the sh translator body), the three message constants, `redirect_shim_script` (renders the translator then the single exec line), `ban_alias_block` (skips REDIRECTED; the redirect-alias branch is gone), `_RC_MAX_BYTES` and `rewrite_outdated_ban_aliases`; the module docstring line on aliases is updated to match.
- `tests/test_guards.py` - nine npx translator tests with a fake pnpm under `tmp_path` (`_npx_with_fake_pnpm`, `_run_npx`, `_recorded`), the alias-block test updated, and five `rewrite_outdated_ban_aliases` tests.

## Decisions Made

- The npx translator is the only npx layer in the shim. `redirect_shim_script` keeps its name, signature, sentinel and last `exec` line; `REDIRECTED` only holds npx, so the translator is npx-specific by construction (the docstring says so).
- Message copy lives in module constants (`_NPX_NOT_SUPPORTED`, `_NPX_NEEDS_PACKAGE`, `_NPX_NO_COMMAND`). They are interpolated into the sh body with an f-string, so the emitted shim is the same bytes the test pins, and the Python source stays within the 100-column limit (ruff E501 caught the inline version).
- Orchestrator decision 1 (plan R1-19) is implemented as written: `ban_alias_block()` skips every name in `REDIRECTED`, exactly like `GLOBAL_REDIRECTED`.
- `rewrite_outdated_ban_aliases` pairs the begin and end markers the way `apply_block` does (last begin, first end after it). A file whose block already matches `ban_alias_block()` is skipped without a write.
- The warn path sanitizes the error's first line as well as the path, since `str(exc)` can carry a filename with control characters.
