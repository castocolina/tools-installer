A cluster containing `n` means no-exec: allowed. A cluster containing `c` means the first remaining argument is the script: `check_script` it (missing script: refused). Neither: the first remaining argument is a script file that must resolve under `allowed_root` or the checkout roots; no file argument (a script on stdin) is refused.

split every token made only of characters from `;&|()<>` and newline into single operators by longest match against `&&`, `||`, `;;`, `>>`, `<<`, `>&`, `<&`, `&>`, `>|`, then single characters (review R1-21);
