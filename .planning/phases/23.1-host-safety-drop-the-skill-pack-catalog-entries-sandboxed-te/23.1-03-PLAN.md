<objective>
Make the installer's `npx` redirect shim translate npx's package options onto `pnpm dlx` and refuse every npx option it cannot honour, so a flag mismatch can never run a package's default bin.

Output: the new `redirect_shim_script("npx", target)` body and its translation-table tests.
</objective>

Decisions for this plan:
- D-11: an npx-only POSIX-sh translator. Shape (prose, not code): line 1 `#!/bin/sh`, line 2 the sentinel. A first loop rotates over the leading option tokens: `-y` or `--yes` is dropped; `-p` or `--package` takes the next token as the package (no next token, or an empty value, prints the needs-a-package line and exits `EXIT_CODE`) and appends `--package=<value>`; `--package=<value>` is appended as is (empty value: same needs-a-package refusal); any other token that starts with `-` prints the not-supported line and exits `EXIT_CODE`; the first token that does not start with `-` ends the loop. With no command left, print the usage line and exit `EXIT_CODE`. A second loop rotates the remaining command and its arguments behind the collected `--package=` entries, so the positional list ends as the packages in order followed by the command and its arguments unchanged. The last line is the single `exec <shlex-quoted target> dlx "$@"` line (byte-identical to today's last line), so pnpm's exit code is the shim's.
- D-12: a bare `--` before the command is an untranslated option and is refused.
- Messages print the token with `printf` using a fixed format string and the token as a `%s` argument inside single quotes, to stderr, never as the format string itself.
- Out of scope (SPEC): the `GLOBAL_REDIRECTED` npm/pnpm wrappers and their argv rules; the interactive alias block (`ban_alias_block`) is unchanged by this plan.
