<objective>
Make the installer's `npx` redirect shim translate npx's package options onto `pnpm dlx` and refuse every npx option it cannot honour, so a flag mismatch can never run a package's default bin; stop the interactive guard alias block from aliasing `npx` to an untranslated `pnpm dlx`, and provide the rewrite that repairs an existing block at launch (wired by 23.1-09).

Purpose: HOST-02 / SPEC R4. Root cause: `exec <pnpm> dlx "$@"` turned `npx -y -p @opengsd/gsd-core gsd-mcp-server` into `pnpm dlx -y -p ...`, and pnpm 11.18 ran the package's default bin (GSD's global installer) 10 times.
Output: the new `redirect_shim_script("npx", target)` body and its translation-table tests; `ban_alias_block()` without an npx alias; `rewrite_outdated_ban_aliases(rc_paths)` and its tests.
</objective>

Decisions for this plan:
- D-11: an npx-only POSIX-sh translator. Shape (prose, not code): line 1 `#!/bin/sh`, line 2 the sentinel. A first loop rotates over the leading option tokens: `-y` or `--yes` is dropped; `-p` or `--package` takes the next token as the package (no next token, or an empty value, prints the needs-a-package line and exits `EXIT_CODE`) and appends `--package=<value>`; `--package=<value>` is appended as is (empty value: same needs-a-package refusal); any other token that starts with `-` prints the not-supported line and exits `EXIT_CODE`; the first token that does not start with `-` ends the loop. With no command left, print the usage line and exit `EXIT_CODE`. A second loop rotates the remaining command and its arguments behind the collected `--package=` entries, so the positional list ends as the packages in order followed by the command and its arguments unchanged. The last line is the single `exec <shlex-quoted target> dlx "$@"` line (byte-identical to today's last line), so pnpm's exit code is the shim's.
- D-12: a bare `--` before the command is an untranslated option and is refused.
- Messages print the token with `printf` using a fixed format string and the token as a `%s` argument inside single quotes, to stderr, never as the format string itself.
- Out of scope (SPEC): the `GLOBAL_REDIRECTED` npm/pnpm wrappers and their argv rules.
- Orchestrator decision 1 (23.1 reviews, R1-19; binding for this replan, the user may reverse it; SPEC R4 and HOST-02 amended 2026-11-07): interactive `npx` goes through the same translator as the shim. Reason: `ban_alias_block` wrote `alias npx='pnpm dlx'`, so an interactive `npx -y -p <pkg> <bin>` reached pnpm untranslated and could still run the package's default bin, against the phase goal. Mechanism chosen (Claude's discretion between "drop the alias" and "point the alias at the shim"): `ban_alias_block()` skips every name in `REDIRECTED` exactly as it skips `GLOBAL_REDIRECTED`, and the `REDIRECTED` branch of its loop goes. Why this one: a one-line alias cannot reproduce the translator, the same reason the npm/pnpm wrappers already have no alias (the docstring states it); it needs no new parameter through the `write_ban_aliases` callers in `installer/app.py` and `installer/policy.py`; and where a real npx precedes the shim dir on PATH, that npx parses its own `-y`/`-p` (no mismatch) while `guard_path_warning` already flags the PATH order. The docstring paragraph that defended the redirect alias is rewritten to say npx, npm and pnpm rely on the PATH shim alone.
- `rewrite_outdated_ban_aliases(rc_paths: Sequence[Path]) -> tuple[tuple[str, str], ...]` (orchestrator decision 1, the launch repair half; 23.1-09 wires it into `_launch_repairs()` over `locations.all_ban_rc_paths()`): for each path, read with `read_capped(path, _RC_MAX_BYTES, follow_symlinks=True)` (a guards-local `_RC_MAX_BYTES = 1 << 20`, the value tweaks uses; do not import the private name); `FileNotFoundError`, a `None` read, `UnicodeDecodeError` or any other `OSError` on the read means skip with no line (the legacy-alias strip already reports an unreadable `~/.myshellrc`); split into lines, find the last `BAN_BEGIN` line and the first `BAN_END` line after it (the `apply_block` pairing); no such pair means skip (never add a block); the lines from begin to end inclusive equal to `ban_alias_block().split("\n")` means skip; otherwise call `write_ban_aliases(path)` (the guard's own writer, which replaces exactly that block through `apply_block` and leaves every other line as it was) and return the ok line; an `OSError` from the write gives the warn line with the first line of `exc.strerror or str(exc)`. `{path}` is `sanitize_log_line(display_path(path))`.
