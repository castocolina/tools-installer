- D-24 (shapes): `@dataclass(frozen=True) class PathState` with `entries: frozenset[str] | None` (directory listing, raw `str` names from `os.listdir(str)`), `mtime_ns: int`, `size: int | None = None`. - `fingerprint(home, overrides) -> dict[str, PathState | None]`; `fingerprint_diff(before, after) -> list[str]`, one line per changed label in sorted order: `{label}: created`, `{label}: removed`, `{label}: added {sorted names!r}, removed {sorted names!r}`, or `{label}: changed (mtime or size only)`.
