## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | pytest + pytest-xdist 3.8.0 + coverage (`fail_under = 90`); Textual pilot for screens |
| **Config file** | `pyproject.toml` `[tool.pytest.ini_options]` (`addopts = "-q"`); `tests/conftest.py` (scratch HOME, Popen guard, real-HOME fingerprint — this phase widens both) |
| **Quick run command** | `uv run pytest -q -p no:cacheprovider tests/test_<module>.py --no-cov` |
| **Full suite command** | `make validate && make test` |
| **E2E** | `make e2e` (`scripts/container-e2e-verify.sh all`, disposable Fedora container) — the only place real packages are installed or removed (HOST-05) |
| **Estimated runtime** | ~90 s full suite locally (6–10 workers); ~10 min on the macOS CI runner |

## Sampling Rate

- **After every task commit:** the touched module's test file with `--no-cov`
- **After every plan wave:** `make validate && make test`
- **Before `/gsd-verify-work`:** full suite green, skip count == 6 on this host (baseline 4 + the two `with-fd` tests per D-19), `make validate` (vulture) green
- **Max feedback latency:** 120 seconds
