- Phase-gate inputs: the R7 baseline in 23.1-04-SUMMARY.md and the skip list pasted in 23.1-10-SUMMARY.md.

Decisions for this plan:
- D-22: `INTERNET_FAMILIES = frozenset({socket.AF_INET, socket.AF_INET6})`; `guarded_socket_init(original, describe)` returns an `__init__` replacement that raises `AssertionError("the test {nodeid} tried to open an internet socket ({family name}); fake the network call instead")` for an internet family (the default family counts when no fileno is given) and otherwise calls `original`; `guarded_getaddrinfo(describe)` returns a replacement raising `AssertionError("the test {nodeid} tried to resolve {host!r}; fake the network call instead")`. The autouse `no_internet_sockets(request, monkeypatch)` patches `socket.socket.__init__` and `socket.getaddrinfo` with `describe = lambda: request.node.nodeid`. Patching the class applies to every thread; no thread-local state.
- D-21: `GUARDED_OS_FUNCTIONS = ("system", "execv", "execve", "execvp", "execvpe", "spawnv", "spawnve", "spawnvp", "spawnvpe", "posix_spawn", "posix_spawnp")`; `guarded_os_call(name, original, check)` returns a wrapper that builds the argv per family (`system(cmd)` -> `["/bin/sh", "-c", cmd]`; `exec*(path, args, ...)` -> `[path, *args[1:]]`; `spawn*(mode, path, args, ...)` -> `[path, *args[1:]]`; `posix_spawn*(path, argv, env, ...)` -> `[path, *argv[1:]]` with that env), calls `check(argv, env)` and then the original with the untouched arguments. The autouse `no_unchecked_os_exec(monkeypatch)` installs a wrapper for each name present on `os`, with `check` bound to `check_launch(..., cwd=None, policy=<worker policy>)`. The check is pure, so a second pass over the same argv gives the same verdict.
- Exec-family behavior is tested through the factory with a recording `original` (a live refused `os.execv` would be harmless, but an allowed one would replace the test process), plus a live assertion that `os.execv` is the wrapper inside a test.
