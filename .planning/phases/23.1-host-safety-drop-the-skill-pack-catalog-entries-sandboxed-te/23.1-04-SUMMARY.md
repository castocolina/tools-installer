## Deviations from Plan

### Auto-fixed Issues

None needing a rule beyond the plan's own scope. Minor choices recorded here:

- **Test names:** the parametrized `test_glued_operators_are_split_before_checking`, `test_precommand_words_and_fd_redirections_are_skipped`, `test_string_running_builtins_are_refused` and `test_path_assignments_are_refused` are split into `_allowed`/`_refused` (and `_but_...pass`) variants that keep the plan's name as a prefix, so every `-k` selector in the plan still matches and the plan's pass-count floors (18, 10, 13) are met by the split ids. The "outside fake named `2` / `noglob`" case is `test_precommand_words_and_fd_redirections_are_skipped_host_program_refused`. A no-argument shell has its own test, `test_shell_scripts_refuse_a_shell_with_no_arguments`.
- **`shell=True` with a list argv:** checked as `["/bin/sh", "-c", *argv]` (what `subprocess` actually does) rather than as a plain argv; the plan only specified the `str` form.
- **stdbuf unknown option:** an option other than `-i/-o/-e/--input/--output/--error` before the command is refused (fail closed), a case the plan left open.
- **Task 1 `-c` handling:** the Task 1 interpreter branch refused `-c` outright ("cannot check shell scripts yet", fail closed) until Task 2 replaced it; it never reached a commit boundary on its own that mattered, since nothing is wired.
