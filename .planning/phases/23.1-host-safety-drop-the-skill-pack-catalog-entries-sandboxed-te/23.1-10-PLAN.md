Decisions for this plan:
- D-16: `pytest_configure(config)` in conftest (1) writes `os.environ[OVERRIDES_STASH] = json.dumps(captured)` only when absent, (2) strips PATH with `host_free_path`, (3) builds the link dir and prepends it when it holds a link, (4) deletes every name `env_names_to_clear(os.environ)` returns. `_HOME_OVERRIDES = capture_home_overrides(os.environ)` at import reads the stash when present, else the live variables. The per-test fixture re-applies the clearing with `monkeypatch.delenv` and PATH with `monkeypatch.setenv("PATH", host_free_path(..., keep=_INTERPRETER_DIR))`.
- `OVERRIDES_STASH = "TOOLS_INSTALLER_TEST_HOME_OVERRIDES"`; `HOME_OVERRIDE_NAMES = ("UV_TOOL_DIR", "PNPM_HOME", "VOLTA_HOME")`. The stash is needed because workers import conftest after the controller cleared the variables; without it they would watch only the defaults.
- `host_free_path(path_value: str, *, real_home: Path, linuxbrew: Path = LINUXBREW_PREFIX, keep: Path | None = None) -> str`: drops empty entries and entries whose `os.path.realpath` is under the realpath of `real_home`, under `/run/user`, or under the realpath (and the literal form) of `linuxbrew`; always keeps `keep` (compared by realpath, so a `TMPDIR` under HOME cannot strip the link dir); keeps order; survives a symlink loop.
- `CLEARED_ENV_NAMES` (exact): CLAUDE_CONFIG_DIR, CODEX_HOME, XDG_CACHE_HOME, XDG_STATE_HOME, GH_TOKEN, GITHUB_TOKEN, ZDOTDIR, ZSH, PNPM_HOME, VOLTA_HOME, XDG_CONFIG_HOME, XDG_DATA_HOME. `CLEARED_ENV_PREFIXES` (start of name, case-sensitive): OPENCODE_CONFIG, UV_, HOMEBREW_; plus `npm_config_` matched case-insensitively. `env_names_to_clear(environ) -> tuple[str, ...]` (sorted). Values are never printed.
- D-17 (location detail): the link dir is a per-process `tempfile.mkdtemp(prefix="tools-installer-interpreters-")` removed by `config.add_cleanup`, not `<basetemp>/interpreters/`: pytest exposes no public base-temp accessor before collection (the factory is the private `config._tmp_path_factory`), and reaching it would need a new pyright suppression or `getattr` with a constant (ruff B009). The location does not change the allowlist: the links resolve to the host interpreters, which 23.1-04 allowlists by realpath. Reversible: one function.
- `link_interpreters(link_dir: Path, *, stripped_path: str, original_path: str) -> bool`: for each of sh, bash, zsh, when `shutil.which(name, path=stripped_path)` is None and `shutil.which(name, path=original_path)` finds it, symlink `link_dir/name` to its realpath; returns whether any link was made. Never links `python3`.
- One link dir per run, not per process (review R1-41): `INTERPRETER_DIR_STASH = "TOOLS_INSTALLER_TEST_INTERPRETER_DIR"`. In `pytest_configure`, when the stash names an existing dir (a worker inheriting the controller's), that dir is `_INTERPRETER_DIR`, it is passed as `keep` to the configure-time strip, and no new dir is made; otherwise the process makes the dir, links into it with `original_path` = PATH before the strip, prepends it once and writes the stash only when a link was made (else removes the empty dir and leaves `_INTERPRETER_DIR` None). The controller's `config.add_cleanup` removes the dir after its workers have exited. Without the stash, a worker whose base temp sits under HOME would strip the controller's dir from PATH and every zsh test there would skip.
- The host's zsh (reviews R1-42, R1-43): `HOST_ZSH_STASH = "TOOLS_INSTALLER_TEST_HOST_ZSH"`, written once by the first process before the strip, as the realpath of `shutil.which("zsh", path=<PATH before the strip>)` or the empty string; `host_zsh() -> Path | None` reads it (no stash, as when a test module is imported outside pytest: the live `shutil.which("zsh")`). Its readers are `test_zsh_resolves_when_the_host_has_one` and `test_the_interpreter_dir_is_prepended_once`. The import-time `HOST_HAS_ZSH` constant is not created (it had two definitions and no reader).
- Stash names start with `TOOLS_INSTALLER_TEST_`, which no cleared prefix matches; their values are paths and JSON of paths, never secrets.
