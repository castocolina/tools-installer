# Phase 23.1 Plan 08: Skill-pack consumers removed from the headless route, the refresh worker and the Owner cell

**The headless route, the TUI refresh worker and the catalog Owner cell no longer read or run skill-pack state; one refresh pass publishes once and the Owner column shows owner labels only.**

## Performance

- **Duration:** ~35 min (estimated)
- **Tasks:** 2 of 2 completed, one commit each (test and implementation together)
- **Files modified:** 7

## Accomplishments

- `run_wizard`'s synchronous pass runs only `refresh.refresh(tools)`; its docstring no longer mentions skill-pack host answers.
- `_refresh_worker` runs one pass and posts one `RefreshPublished`; the skills stage, its error merge and its second post are gone.
- `_owner_cell` returns the owner label (with ` ≠ policy` when off-policy) for every tool; `_skill_owner_cell`, `_OWNER_CELL_MAX`, the pack host-label import and the `SkillHostStatus` import are removed.
- The pack-only UI tests are removed, and one test that pinned the pack Owner cell now pins it blank (see Deviations).

## Task Commits

1. **Task 1: the headless --all route plans after one refresh pass with no skills stage** - `3afb9fe` (refactor)
2. **Task 2: the TUI refresh worker publishes once per pass and the Owner cell has no pack branch** - `a2da2a2` (refactor)

Plan metadata: this SUMMARY is committed separately as `docs(23.1-08)` on top of `a2da2a2`.

## Files Created/Modified

- `installer/app.py` - `run_wizard` runs no skills pass; docstring updated.
- `installer/wizard_app.py` - `_refresh_worker` single pass and single publish; `RefreshPublished` docstring describes one publication per pass.
- `installer/catalog_tui.py` - `_owner_cell` without the pack branch; `_skill_owner_cell`, `_OWNER_CELL_MAX`, `OWNER_LABELS` and `SkillHostStatus`/`SKILL_HARNESS_LABELS` imports removed.

## Decisions Made

- Consumers were removed and producers kept, as the plan directs. `refresh_skills`, `skill_hosts` and the pack state stay in `version_status.py` and its tests, untouched; 23.1-12 removes them.
- The `RefreshPublished` docstring was updated, since it described a two-stage post that no longer exists.
