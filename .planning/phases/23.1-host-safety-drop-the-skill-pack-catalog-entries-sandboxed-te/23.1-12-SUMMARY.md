# Phase 23.1 Plan 12: Refresh service and version cache without skill-pack state Summary

**The version-refresh service no longer probes, scans or caches skill packs: only host detection for hook registration is kept, an old cache with a `skills` key still loads, and the service's `skill_home` parameter is now `home`.**
