# Phase 23.1 Plan 13: Retired-receipt removal pipeline Summary

**A retired receipt is removed through the existing remover: a placement-shape proof (bin-dir link/file, paired opt dir, app bundle) stands in for the registry formula after the unchanged drift check, everything else is listed and kept, and manager-kind or empty receipts retire with a sentence and no command.**

## Accomplishments

- `_placement_shape` proves, for a retired receipt, only: a `github_release`/`tarball` `link` or `file` that is a direct child of the default bin dir; a `dir` equal to `opt_dir(N)` where `N` names a `link` recorded in the same receipt as a direct child of the bin dir; for `app`, a `dir` directly under `applications_dir()` and a bin-dir `link`. A name of `""`, `.`, `..`, containing `/` or NUL is never proven. `script` trees and leaves and every other kind are never proven.
- `_receipt_proof` keeps `receipts.drifted(receipt, rehash=verify)` first, so a drifted file proves nothing and the deletion-time re-hash in `remove_tool` still refuses a swapped file.
- `plan_removal` lists a retired receipt's unproven, still-existing recorded paths in `yourself` (none for manager kinds).
- `removal_plan` gives a retired manager-kind tool `hint="remove it yourself: {manager} {package}"` (no argv) and a retired tool with nothing removable and nothing listed the new level `receipt`.
- `remove_tool` handles `fresh.level == "receipt"` before the `not (paths or argv)` refusal: refuses as changed if the preview carried paths, argv or an unregister, else retires the receipt with `Retired the {id} receipt; there was nothing to delete.` or `Retired the {id} receipt; {manager} {package} stays installed — remove it yourself.`.
- `run_uninstall` keeps retired tools out of the catalog `paths`/`yourself`, prints the `retired — no longer in the catalog` block after the catalog `render_remove_yourself` (proven path lines, `remove it yourself: ...`, the manager hint, or `nothing to delete; confirming retires the receipt`, all `markup=False, soft_wrap=True`, sanitized), and no longer answers "nothing to uninstall" for a machine whose only footprint is a retired receipt row.
