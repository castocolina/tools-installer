# Phase 15.8 — Security

> Per-phase security contract: threat register, accepted risks, and audit trail.

---

## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| Shell rc files (`~/.zshrc`, `~/.bashrc`, `~/.myshellrc`, `~/.shellrc`) | User-owned, user-editable config files this installer reads and rewrites | PATH export lines, source lines, managed marker blocks |
| Real-shell subprocess tests | Test harness spawns real `bash`/`zsh`/`sh` to prove emitted shell syntax behaves correctly | Minimal explicit `env={"PATH":..., "HOME": tmp_path}`, never the real environment |
| Container E2E script (`scripts/container-e2e-verify.sh`) | Appends a PATH guard block inside a disposable container, re-sourced to prove idempotence | Shell script bytes only, no host state |
