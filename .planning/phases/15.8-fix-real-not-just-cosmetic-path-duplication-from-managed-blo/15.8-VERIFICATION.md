# Phase 15.8: Fix real (not just cosmetic) PATH duplication from managed-block sourcing — Verification Report

**Phase Goal:** Every PATH entry this installer writes into a shell rc file is self-deduping at runtime. A nested or child shell that re-sources the file N times ends up with exactly one copy of each managed directory, proven by running real shells rather than by asserting on the emitted string. Existing installations migrate automatically the next time apply/fix runs, through the block-replacement mechanism that already exists. No PATH-writing code in the repo emits a plain unconditional export any more. A machine carrying a generic ~/.shellrc ends up with one canonical file (~/.myshellrc) plus a marked stub, with the foreign content copied forward before anything is replaced.
