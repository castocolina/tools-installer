**The property this test creates, stated precisely before any code.** The defect this phase
exists to kill is not "a PATH assignment appears in our source". It is "our source emits, into a
file a shell re-sources, a PATH assignment that PREPENDS to the existing PATH without checking
first" — a self-referential assignment whose value contains `$PATH`. That shape accumulates one
extra copy per evaluation, which is the bug. A TOTAL assignment, whose value does not reference
`$PATH`, replaces PATH outright and is idempotent by construction no matter how often it runs;
it cannot produce a duplicate and is not the defect. The needle targets the accumulating shape,
and that narrowing is the invariant's definition, not a concession to make a test pass.

**Why this is an AST scan and not a line scan.** The cross-AI review (MEDIUM-03) showed the
line-local version of this test was bypassable four different ways: a bare prepend sitting within
two lines of an unrelated case-guard opening was exempted by the lookback, a shape assembled
across several Python statements was invisible to a needle that only ever saw one line, the whole
of `rcclean.py` was exempt rather than just its documentation, and `setup.py` was not scanned at
all. All four are closed below by parsing instead of grepping. A pleasant side effect: `ast` does
not see comments at all, so this test can never be invalidated by a comment someone writes near
the code it guards.

Write the test first and watch it pass for the right reason. Then confirm it can actually fail,
against four fixtures — see the seeded-violation list below. Never seed a violation into a
committed source file. A source-scanning invariant that has never been seen to fail is not an
invariant.

Factor the scan into module-level helpers in the test file so the real scan and every seeded
proof run the SAME code against different roots. A second, test-only copy of the scan logic would
let the two drift, and the copy that guards the repo is the one that would rot. Shape:

- `_reconstruct(node) -> str | None` — the shell text a string-producing expression builds:
  `ast.Constant` holding a `str` returns its value; `ast.JoinedStr` returns its constant parts
  joined with a single placeholder token standing in for each `FormattedValue`; `ast.BinOp` with
  an `Add` operator returns the concatenation of its two reconstructed sides; anything else
  returns None. The placeholder token must contain no colon and no dollar sign, so it can never
  manufacture a false hit on its own.
- `_accumulating_hits(root: Path) -> list[Hit]` — parses every `*.py` under `root` (recursively,
  sorted, plus `root/../setup.py` handled by the caller passing an explicit file list; keep the
  helper taking a list of files so the seeded fixtures reuse it unchanged). Each `Hit` records
  the file's path relative to the scan root, the line number, the enclosing function's name (or
  None at module level), whether the node IS that function's or module's docstring, and the
  reconstructed text.

A hit is produced at two levels, both using one shared needle:

- NODE level: run the needle over each individually reconstructed string-producing node.
- SCOPE level: for every function body and for module level, join the reconstructed texts of all
  string-producing nodes in that scope in source order, EXCLUDING the scope's own docstring, and
  run the needle over the join. This is what catches a shape assembled from fragments across
  statements. Excluding the docstring is principled and load-bearing: a docstring is
  documentation, never concatenated with runtime fragments, and including it would let
  `rcclean.py`'s documentation leak into its own function's reconstructed text and defeat the
  narrow exemption this revision exists to install.

**The needle**, one compiled pattern applied to reconstructed text: an assignment to the PATH
name — optional `export` prefix, a negative lookbehind on a word character so a longer variable
name ending in PATH is not a false hit — followed later in the same reconstructed text by a
reference to the PATH expansion in EITHER the bare-dollar or the braced spelling. Both halves
together identify the accumulating shape.
