Execute D-02a: delete the two dead functions in `installer/shellrc.py` rather than porting them
to the new emitter, and install a repo-level invariant test so the "no second site left behind"
property survives this phase instead of depending on anyone remembering it.

Purpose: D-02 requires that no known site is left carrying the plain-export defect for a future
phase to rediscover. D-02a (the dated 2026-09-22 correction in 15.8-CONTEXT.md, which is
authoritative over D-02's original text where they conflict) established that the site D-02
names — `write_pnpm_home` at `installer/shellrc.py:200` — has zero callers, as does
`existing_managed_bin_dirs` at `:72`, and that deleting dead code satisfies D-02's requirement
more completely than rewriting it.

Output: a smaller `installer/shellrc.py`, and a test that fails if a plain PATH export is ever
reintroduced anywhere under `installer/`.

**The executor re-verifies before deleting.** D-02a says explicitly: delete unless a live caller
this correction missed is found, in which case D-02's original instruction (emit the guarded
form) applies unchanged to whichever site is actually live, and the branch taken must be stated.
Task 1 therefore starts with the verification, not with the deletion, and carries both branches.

**What deletion does NOT change.** pnpm's bin directory stays on PATH: `installer/registry.toml`
declares it as an ordinary per-tool `bin_dir`, which `collect_bin_dirs` folds into
`managed_block`'s own list. The live pnpm duplicates recorded in 15.8-CONTEXT.md's evidence came
through that path, not through `write_pnpm_home` — which has been unreachable since 2026-09-11.
Deleting it removes no user-visible behavior; plan 15.8-01 already fixed the mechanism that
actually writes pnpm's directory.

`~/.shellrc`; none runs `make setup`, `make fix` or `make uninstall`.
