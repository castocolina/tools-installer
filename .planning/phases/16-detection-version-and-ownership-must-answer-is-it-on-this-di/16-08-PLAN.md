<objective>
Build the guard-in-place WRITE action (D-21) on the corrected detection from plan 16-03. It
excludes other tools' marked blocks (D-22) and is preceded by phase 15.8's exact backup convention
(D-23). The per-file Doctor opt-in UI is plan 16-11.

Purpose: Doctor names foreign unguarded PATH writers but can only tell the user to edit them by
hand. ROADMAP asks to offer guarding them with 15.8's guardrails: backup, byte-exact refusal, and
never deleting an indented line inside an if-block. D-21 resolves the last guardrail by rewriting
the line, never deleting it. The guard idiom itself already exists (`path_export_guard`) and is
proven in real shells.

Output:
- `PathWriterLine` records and `path_writer_lines`, with foreign-marker detection and a
  guardability verdict.
- `guard_path_writers(rc_path, lines) -> PathGuardOutcome` in shellrc.py, sharing the backup and
  snapshot primitives with `consolidate_shellrc`.

Host-safety rule: no task writes to real rc files. Every write test uses `tmp_path`. Real-shell
syntax checks use `bash -n` on a tmp file with an explicit minimal env (copy the
tests/test_prune_tmp_linux_sh.py subprocess precedent).

Output harness note: if `uv run pytest` prints a false "No tests collected", re-run via `.venv/bin/pytest`.
</objective>

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-16-21 | Tampering | `guard_path_writers` rewrite | high | mitigate | Only single-dir prepend lines are rewritten, with no deletion. The output is `path_export_guard` (proven set -u-safe, no empty PATH component). `bash -n` is run in tests. Lines inside foreign blocks are refused. |
| T-16-22 | Tampering | stale scan -> write at the wrong index | high | mitigate | Per-line text re-verification plus a `_snapshot_matches` identity+bytes check after backup creation. On mismatch, refuse and roll back the backup. |
| T-16-23 | Tampering | symlinked rc file write-through | high | mitigate | `_path_hazard` (shared with consolidation) refuses symlinks and non-regular files before any read. |

| T-16-25 | Elevation | shell injection via directory text | medium | mitigate | `directory` comes from the managed-dir set (trusted registry + `Path.home()`), never from the foreign line's text. `path_export_guard`'s trust caveat carries over. |
