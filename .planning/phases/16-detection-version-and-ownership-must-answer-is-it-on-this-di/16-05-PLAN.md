<objective>
Real-owner-wins attribution: report whichever manager actually owns the live binary, even when the
registry declares a different policy. Expose the data the row needs to show the conflict, and make
`u` act through the real owner with an honest note.

Purpose: the live Bazzite defect (CONTEXT.md Specifics). groovy/gradle/maven/java read
"(source unknown)" and refuse to update, while `brew list --formula` lists groovy, gradle, maven
and openjdk. `_collect_candidates` only ever consults DECLARED methods. CONTEXT.md names
`install_ownership.path_owner_package` as the inverse "resolve from the path backward" pattern to
mirror. For Homebrew the inverse query needs no subprocess: the Cellar layout
(`<prefix>/Cellar/<formula>/<version>/...`) names the formula, and the already-read inventory
confirms it.

Output:
- `_brew_cellar_formula`, an undeclared-brew candidate, and the `ManagerOwnership.off_policy` field.
- `declared_manager_label`, `also_installed_note` and `active_path_note` helpers.
- The off-policy update note.

Output harness note: if `uv run pytest` prints a false "No tests collected", re-run via `.venv/bin/pytest`.
</objective>
