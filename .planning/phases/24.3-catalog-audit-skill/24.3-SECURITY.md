## Focus-area findings

- **`--state` guard.** Refuses a symlink leaf, the default state, HOME dot directories (written and
  resolved forms, so a parent symlink into `~/.claude` is caught), the checkout regardless of
  `--repo`, and any existing file that is not a flat string map. The check runs before the
  record-exists check and before verify-registry, which runs without `--write`.
- **Run-dir confinement.** Date full-match plus a real calendar date, a required `.planning`
  ancestor, symlink refusal from the date dir up to `.planning`, a leaf symlink refused on every
  write, `verify-registry.md` and `scripts.md` written once (exit 73 on a re-run). Ids are registry
  ids.
- **Redaction.** Secret patterns cover GitHub (`gh[pousr]_`, `github_pat_`), npm, GitLab, Google,
  OpenAI-style, Slack and AWS keys, private keys and `Authorization`/`Bearer`. The home path is
  matched as written, resolved and under both `/home` and `/var/home`. Applied to reports and to
  findings on add and on read; facts and the verify record are `~`-relative.
- **Upstream text.** Treated as data in SKILL.md; free text (`add-finding`, `write`) goes to
  `python -m installer.catalog_audit` with single quotes, never through `make ARGS`, and a test
  fails on a backtick or `$` inside any documented `ARGS="…"`.
- **`container:` evidence.** Accepted only when the named file is a regular, non-symlink file whose
  resolved path is inside the run directory, on add and again on read (`_transcript_problem`).
  Content is not checked (R1).
- **No host mutation, telemetry off.** `facts` execs only `[binary, "--version"]` and `gh auth
  token`. Both codegraph probe paths set `CODEGRAPH_TELEMETRY=0` and `DO_NOT_TRACK=1`
  (`versions.py:346`, `postinstall.py:236`).
- **`permissions`, retired key, D-11.** Written only where absent; a retired `permission` blocks the
  write and reads `set_by_you` unless the ledger records that exact value (D-11 amendment, R5).
