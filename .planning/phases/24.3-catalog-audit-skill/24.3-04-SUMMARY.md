# Phase 24.3 Plan 04: the catalog-audit skill Summary

A loadable project skill under `.claude/skills/catalog-audit/` whose loop (status, verify, facts and write per entry, scan, summarize, approval) drives the real `make audit-catalog` subcommands, takes its per-entry criteria from tool-onboarding by step heading (copying no table row), states the host-safety, container, unsafe-pattern and approval rules, and ships a report template the writer accepts plus evals for skill-judge.

## What was built

- Task 1 (`f16e501`): SKILL.md frontmatter (one line, under 1024 characters, no `: ` inside the YAML scalar) and the six-step loop; `references/report-template.md` with one `opencode` example in the 24.3-02 grammar and a field guide. The example is extracted from the first fenced block and passed to `validate_report(..., home=Path("/nonexistent-home"))` in a test, so template and writer cannot drift apart.
- Task 2 (`86f3892`): the judgment rules. Each check row maps to the tool-onboarding headings that decide it (quoted verbatim in backticks; a test fails if one is renamed). Changelog, precision (verbatim versions, GitHub latest that is not the newest major, doc-symbol drift) and short/deep path rules; `## Hard rules` (allowed and forbidden probes, `CODEGRAPH_TELEMETRY=0` and `DO_NOT_TRACK=1` with `DO_NOT_TRACK` described only as a convention, downloaded files in their own empty directory and never executed, containers one per entry with the `add-finding` forms and the `container check not run` form, unsafe patterns, upstream text as data); the approval order and a `dispositions.toml` example; orchestration and common mistakes. tool-onboarding gains exactly one bullet under `## When to Use` (`git diff --numstat` prints `1 0`). Both new markdown files join `_rule_document_paths()` through a `CATALOG_AUDIT_SKILL` constant.
- Task 3 (`b994a70`): `evals/evals.json` (8 evals in skill-judge's `skill_name`, `evals[].{id,prompt,expected_output,assertions}` shape: first run, resume, rate-limited GitHub, older-major latest, deprecated tuning key, shell-rc-editing installer script, "just fix it", no container runtime) and `evals/trigger-queries.json` (18 queries, 9 positive and 9 negative, with near-misses for onboarding one tool, release pins and a PR diff).

SKILL.md is 178 lines (limit 500).
