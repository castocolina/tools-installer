## Deviations from Plan

**1. [Rule 3 - Blocking] `codegraph` CLI not run**
- The plan's "start with `codegraph sync`" contradicts its own binding rule "no `opencode`/`pi`/`codegraph` command"; the prohibition won and the code was read directly (the orchestrator said to do so when the rules forbid it).

**2. [Plan staging] Writer hygiene lives in Task 1, not Task 3**
- `validate_report(text, entry_id, *, home)` takes `home`, and vulture flags an unused argument at 100% confidence, so the secret, absolute-home, footer and unreachable-upstream guards landed with the grammar in Task 1. Task 3 added the title-date check and the tests that pin every guard; its RED is therefore narrower than the plan implied.

**3. [Rule 1 - plan line numbers stale] `tests/test_versions.py` fakes**
- The plan names fakes at `:596`, `:609`, `:616`; at HEAD the `probe_version_output` fakes are at `:658`, `:672`, `:678` (`:546`/`:557` fake `_default_probe_version`, which is unchanged). Migrated the three real ones to take `env: Mapping[str, str] | None = None`, added an `OSError` branch and `test_version_probe_turns_vendor_telemetry_off`.

**4. [Plan wording] `latest:` lines carry the source URL after an `unknown:` reason too**
- `- latest: unknown: HTTPError: HTTP Error 403: ... (https://...)`: the reason is first so the writer's `startswith("unknown:")` rule holds, the URL stays for the agent.

**5. [Plan wording] `entry_facts` gained a keyword**
- `entry_facts(tool, tools, seams, *, verified=None)` because `Tool` does not hold the `verified` date; `main` reads it from the registry TOML.

**6. [Plan wording] `main` gained `gh=`**
- `main(argv, *, registry, seams, root, gh)`: `test_main_never_prints_the_token` needs a way to fake `gh auth token` when no `Seams` are injected. `gh` is only used when `facts` builds the default seams.
