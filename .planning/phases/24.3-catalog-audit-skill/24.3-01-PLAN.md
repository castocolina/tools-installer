## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| registry.npmjs.org -> installer | untrusted JSON over HTTPS decides a displayed version |
| registry.toml -> URL builder | a registry string becomes part of a request URL |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-24.3-01 | Tampering | `resolve_npm_latest` URL | medium | mitigate | the package name must fully match `NPM_PACKAGE_RE` at registry load and again before the fetch, and is quoted with only `@` kept, so no path or query can be injected; `test_resolve_npm_latest_refuses_bad_names`, `test_latest_npm_param` |
| T-24.3-02 | Information Disclosure | `urlopen_fetch` token | high | mitigate | the npm fetch uses `urlopen_fetch` unchanged, which sends a GitHub token to api.github.com only; no new client is written |
| T-24.3-03 | Denial of Service | refresh pass | low | mitigate | npm reads count toward `MAX_FETCHES_PER_REFRESH` and follow the cache backoff; a failure keeps the prior value and marks it stale; `test_npm_fetches_count_toward_the_refresh_budget` |
| T-24.3-SC | Tampering | npm/pip/cargo installs | high | accept | this plan installs no package; npm is only read over HTTPS |
