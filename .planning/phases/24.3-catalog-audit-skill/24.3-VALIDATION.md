## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | pytest 8 + pytest-xdist + pytest-cov (`fail_under = 90`, coverage source `installer`); pyright strict, ruff, bandit, vulture. Autouse fixtures in `tests/conftest.py` refuse host toolchain exec and internet sockets, so every probe, fetch, `gh` and `podman` call in `installer/catalog_audit.py` is an injected callable (its CLI wires the real ones); tests run under the 23.1 sandbox (scratch HOME, `tests/home_fingerprint.py`) |
| **Config file** | `pyproject.toml` (`[tool.pytest.ini_options]`, `[tool.coverage.report]`), `tests/conftest.py`, `tests/sandbox.py`, `tests/home_fingerprint.py` |
| **Quick run command** | `uv run pytest <touched test files> -n 0 --no-cov -q` |
| **Full suite command** | `make validate && make test` |
| **Orchestrator only** | container e2e (`scripts/container-e2e-verify.sh opencode-v2`, subcommand added by the OpenCode 2 plan), the first full audit run (real network, per-entry subagents, disposable containers for flagged entries) and `make verify-registry` (real upstream, scratch `--state`); never on the host by an executor |
| **Estimated runtime** | quick < 60 s per file set; full suite ~2 min locally; container e2e, first audit run and `verify-registry` are long and run only on the orchestrator |

---

## Sampling Rate

- **After every task commit:** the quick command for the touched test files plus `uv run ruff check installer tests setup.py && uv run pyright` on the touched modules
- **After every plan wave:** `make validate && make test`, then push main and watch CI on both OSes
- **Before `/gsd-verify-work`:** full suite green, then the orchestrator-only items (first audit run with host fingerprint, container e2e, `make verify-registry` exit 0), then the skill-judge verdict at >= 80.0
- **Max feedback latency:** 60 seconds per task command
