## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | pytest 8 + pytest-xdist + pytest-cov (`fail_under = 90`, coverage source `installer`); pyright strict, ruff, bandit, vulture, shellcheck. Autouse fixtures in `tests/conftest.py` refuse host toolchain exec and internet sockets (a refused launch fails its test even when the code catches it), so every probe, fetch, `gh`, `codegraph` and `podman` call is an injected callable or a replaceable module seam; tests run under the 23.1 sandbox (scratch HOME, `tests/home_fingerprint.py`) |
| **Config file** | `pyproject.toml` (`[tool.pytest.ini_options]`, `[tool.coverage.report]`), `tests/conftest.py`, `tests/sandbox.py`, `tests/home_fingerprint.py` |
| **Quick run command** | `uv run pytest <touched test files> -n 0 --no-cov -q` |
| **Full suite command** | `make validate && make test` |
| **Orchestrator only** | the first full audit run (24.3-05 Task 2: real network, per-entry subagents, disposable containers for flagged entries, host fingerprint), the landing container check (`scripts/container-e2e-verify.sh audit-landing`, 24.3-11 Task 2) and the skill-judge rounds (24.3-10 Task 2); never on the host by an executor. `make verify-registry` runs only with a scratch `--state` (executors may run it that way in 24.3-06 Task 3 and 24.3-11 Task 1) |
| **Estimated runtime** | quick < 60 s per file set; full suite ~2 min locally; the first audit, the landing container and verify-registry are long |

---

## Sampling Rate

- **After every task commit:** the quick command for the touched test files plus `uv run ruff check installer tests setup.py && uv run pyright` on the touched modules
- **After every plan wave:** `make validate && make test`, then push main and watch CI on both OSes, and wave 5's gate also includes the landing container check (`scripts/container-e2e-verify.sh audit-landing`, 24.3-11 Task 2), run by the orchestrator before wave 5 is pushed; a failure is fixed with a forward commit before the push; wave 6 pushes on its own after its gate (SPEC R5 ordering edge amendment 2026-11-13)
- **Before `/gsd-verify-work`:** full suite green, the first audit committed with an empty host fingerprint diff, the landing container check passed, `make verify-registry` exit 0 on the final tree, the skill-judge FINAL verdict at >= 80.0
- **Max feedback latency:** 60 seconds per task command
