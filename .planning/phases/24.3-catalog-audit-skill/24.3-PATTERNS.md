### `installer/catalog_audit.py` (CLI, read-only facts + validated writer)

**Analog:** `installer/verify_registry.py`

**Module docstring with exit codes + imports** (lines 1-7, 35-56): module docstring lists exit codes; `from __future__ import annotations`; project imports are absolute `installer.*`. Reuse, do not re-implement:

**Exit-code constants** (lines 58-60): `EXIT_USAGE = 64`, `EXIT_INTERNAL = 70`, `EXIT_WRITE_REFUSED = 73`; reuse the same numbers for bad `--date`/unknown id (64) and a refused report (73).

```python

    release: ReleaseResolver
    head: Callable[[str], str]
    download: Callable[[str, Path], None]
```

Guard runner that must never run (line 186-187):
```python

    raise RuntimeError(f"verify_registry must not invoke install commands: {cmd!r}")
```

**Default (production) probe** (lines 1521-1540): `functools.partial(urlopen_fetch, token=token)` + `functools.cache` around the resolver. Token lookup via `github_token(gh)` (lines 1497-1507, env `GITHUB_TOKEN`/`GH_TOKEN` then `gh auth token`; never print it - see `test_main_never_prints_the_token` `tests/test_verify_registry.py:2492`).

**argparse + main wrapper** (lines 1543-1649): keyword-only injection args on both `_run_*` and `main`; `main` catches everything and returns `EXIT_INTERNAL`:
```python
def main(argv: Sequence[str] | None = None, *, probe: Probe | None = None, gh=..., today: date | None = None) -> int:
    try:
        return _run_verify_registry(argv, probe=probe, gh=gh, today=today)
    except Exception as exc:
        print(f"verify-registry: internal error: {exc!r}", file=sys.stderr)

if __name__ == "__main__":
    raise SystemExit(main())
```

For subcommands use `parser.add_subparsers(dest="cmd", required=True)` (new; no subparser analog in repo - `installer/cli.py` is flag-based). Usage errors print to stderr and `return EXIT_USAGE` (lines 1582-1587).

**Error to "unknown" row** (lines 257-292 `_is_github_rate_limit`, `_release_read_finding`): convert `VersionError`/`HTTPError` (403/429 rate limit) into a finding with a reason instead of raising. Copy this shape for `unknown: <reason>` rows.

**Atomic state/report write** (lines 1492-1494, `installer/atomic.py:76-78`):
```python

    ensure_dir(path.parent)
    atomic_write_text(path, json.dumps(dict(sorted(state.items())), indent=2) + "\n")
```

`atomic_write_text` already does temp-sibling + `os.replace` (`atomic.py:32-56`); RESEARCH Pattern 1 wants a leading-dot temp name that `status` ignores - check `_temp_path` (`atomic.py:32`) before adding a new helper.

**Tolerant JSON/TOML read** (lines 1476-1489 `_load_state`): missing/invalid file -> empty, never raise. Same for an absent `dispositions.toml`.

**Registry write-race refusal** (lines 1600-1605): re-read and compare before writing; raise -> `EXIT_WRITE_REFUSED`. Use for the "two writers same date" edge.

### `installer/versions.py` (npm dist-tags, brew formula, distro resolvers)

**Analog:** `resolve_github_release` (lines 388-401):
```python
def resolve_github_release(repo: str, fetch: Fetch = urlopen_fetch) -> Release:
    try:
        raw = fetch(f"https://api.github.com/repos/{repo}/releases/latest")
        data = json.loads(raw)
    except (OSError, http.client.HTTPException, ValueError) as exc:
        raise VersionError(f"failed to resolve tag for {repo}: {exc}") from exc
    if not isinstance(data, dict):
        raise VersionError(f"unexpected release payload for {repo}")
    payload = cast(dict[str, object], data)
    tag = str(payload.get("tag_name", ""))
    if not tag:
        raise VersionError(f"no release tag for {repo}")
```
Same shape for `resolve_npm_latest(pkg, fetch)` (`https://registry.npmjs.org/-/package/<pkg>/dist-tags` -> `latest`). Types: `TagResolver = Callable[[str], str]`, `Fetch = Callable[[str], bytes]` (lines 18-23). Distro APIs: an HTTP 200 with `{"error":404}` body must raise `VersionError` (RESEARCH anti-pattern). Token is sent to api.github.com only (`urlopen_fetch` 350-365) - do not widen.

## Shared Patterns

### Injected side effects (all new Python)
**Source:** `verify_registry.Probe` (160-166), `postinstall.HookPair` callables, `resolve_status(probe_output=..., resolve_tag=...)` (`version_status.py:459-470`). Every fetch, `--version` probe, `gh`, `podman` is a parameter; `__main__`/`main` wires real ones. Required by `tests/conftest.py` autouse guards.

### Errors become data, not exceptions
**Source:** `verify_registry._release_read_finding` (269-292), `_codegraph_register` (`postinstall.py:189-192`), `VersionError` wrapping (`versions.py:390-394`). Network/exec failure -> `unknown: <reason>` row / warning string.

### Atomic writes only
**Source:** `installer/atomic.py:36-78` (`atomic_write_bytes`/`atomic_write_text`); architecture.md requires `atomic_write_text`.

### Never mutate host / no elevation
`ELEVATION_COMMANDS` (`model.py:554`), `_elevation_head` used in model validation; host-safety tests via `tests/home_fingerprint.py`.
