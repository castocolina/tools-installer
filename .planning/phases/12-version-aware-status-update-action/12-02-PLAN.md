<objective>
Introduce ownership resolution as a real, separate, tested concept, and use it — not install-preference ranking — to decide where each catalog tool's version comes from. Then resolve current-and-latest versions for brew-, cask-, pnpm-, and uv-owned tools using each manager's own report, queried once per manager per refresh pass through a single bounded runner.

Purpose: REQ-manager-version-resolution, and the correctness precondition Plan 12-03's mutating update action depends on. Without ownership, a brew-installed `rg` is queried (and later upgraded) as a GitHub download, because `rg` declares `github_release`, native, and `brew` methods and `_RANK` puts `github_release` (20) ahead of `brew` (40) — see `installer/registry.toml`'s `rg` entry and `installer/resolve.py:12-26`.
Output: `installer/ownership.py` (new), `installer/manager_versions.py` (new), `installer/run.py::run_query` (new), and a Ver column whose source for each row is that row's real owner.
