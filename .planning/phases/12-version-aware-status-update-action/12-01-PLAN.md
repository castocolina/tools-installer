## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub API response -> installer | `resolve_github_tag`'s parsed `tag_name` (untrusted, third-party-repo-controlled JSON) crosses into version comparison and table rendering |
| Installed tool's `--version` stdout -> installer | Arbitrary text from a locally-installed third-party binary crosses into `extract_observed_version` and the Ver cell |
| Local cache file -> installer (next session) | `~/.local/state/tools-installer/versions.json`, writable by anything running as the same local user, is read back as "last known latest version" |
| Background worker thread -> main render thread | Refresh results cross back into Textual UI state via `post_message` |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-12-01 | Tampering | `~/.local/state/tools-installer/versions.json` | low | mitigate | `load_version_cache` type-checks every field and skips a bad entry instead of raising; a tampered entry degrades to "never checked, re-fetch". | T-12-02 | Spoofing | GitHub `tag_name` and local `--version` stdout | medium | mitigate | Both sides of every comparison pass `parse_version`'s strict `_OBSERVED_VERSION` regex; an unparseable or metacharacter-bearing string yields `None` and renders `unknown` instead of being compared or trusted.
