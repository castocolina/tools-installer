## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| npm registry -> version status | the latest version string comes from the network |
| bun global manifest -> update refusal | a user-written range decides whether an update runs |
| ownership -> update argv | the package name in the argv comes from the attributed candidate |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-24.5-13 | Tampering | `update._perform` bun branch | high | mitigate | `bun update -g` keeps the declared range (no latest flag), the declared smoke runs after it, and the package is the registry `npm_pkg` matched through the bun candidate (D-13 tests) |
| T-24.5-14 | Tampering | exact user pin | medium | mitigate | an exact manifest range refuses the update with zero commands (`test_bun_exact_pin_is_not_updated`) |

| T-24.5-16 | Elevation of Privilege | bun resolution for update | medium | mitigate | `resolve_bun()` gives an absolute path; a missing bun fails the update instead of running a bare name |
