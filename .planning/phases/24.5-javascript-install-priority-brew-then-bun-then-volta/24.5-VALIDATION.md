## Sampling Rate

- **After every task commit:** Run the quick command over the test files the task touched
- **After every plan wave:** Run `uv run pytest -n auto -q --no-cov` then `make validate`
- **Before `/gsd-verify-work`:** `make validate && make test` green on the exact tree, then the container `bun-lifecycle` verb and an `audit-landing` rerun (disposable containers, removed afterwards)
- **Phase-gate container check:** `scripts/container-e2e-verify.sh bun-lifecycle` (24.5-09 Task 3). Automated; runs in a disposable Fedora container named `tools-installer-e2e-bun-<pid>` (never a `ti-uat-*` name; the verb sets `CONTAINER_NAME`, `IMAGE` and `DISTRO` itself, so `--distro` cannot redirect it), removed on every exit; passes when the transcript `.e2e-artifacts/container-bun/bun-transcript.log` holds all eleven `TRACER_BUN_*_OK` lines (`TRACER_BUN_VIA_HOMEBREW_OK` included) and ends with `TRACER_LANDING_TEARDOWN_OK` (the teardown now appends its verdict to the transcript), and no `tools-installer-e2e-bun-*` container remains. Then `scripts/container-e2e-verify.sh audit-landing` is rerun once (review R1-02: brew-first plus 24.5-07's script-route override and 24.5-09's landing-driver refactor); it passes with `TRACER_OPENCODE_V2_INSTALL_OK`, no `_FAILED`/`_UNPROVEN` line, `TRACER_LANDING_TEARDOWN_OK` last in `.e2e-artifacts/container-landing/landing-transcript.log`, and no `tools-installer-e2e-landing` container left. Exit 2 is an environment failure (rerun), never a pass.
- **Max feedback latency:** 60 seconds per task
