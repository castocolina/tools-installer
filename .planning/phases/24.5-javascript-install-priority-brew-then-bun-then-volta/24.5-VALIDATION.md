## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | pytest + pytest-xdist (capped to ~40% of threads by `tests/conftest.py`), asyncio_mode auto |
| **Config file** | `pyproject.toml` `[tool.pytest.ini_options]` |
| **Quick run command** | `uv run pytest <files the task touched> -n auto -q --no-cov` |
| **Full suite command** | `make validate && make test` |
| **Estimated runtime** | ~240 seconds (full suite); quick runs ~20-60 seconds |

---

## Sampling Rate

- **After every task commit:** Run the quick command over the test files the task touched
- **After every plan wave:** Run `uv run pytest -n auto -q --no-cov` then `make validate`
- **Before `/gsd-verify-work`:** `make validate && make test` green on the exact tree, then the container `bun-lifecycle` verb (disposable container, removed afterwards)
- **Max feedback latency:** 60 seconds per task
