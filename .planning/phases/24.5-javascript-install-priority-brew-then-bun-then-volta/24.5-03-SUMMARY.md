# Phase 24.5 Plan 03: bun ownership and live inventory Summary

A bun-installed tool now has an owner: owner `bun` is attributed from bun's global tree read as files (manifest names, installed versions from each member's `package.json`), carries its version, writes an honest receipt, generates its own removal hint and label from one argv row, and reads `unknown` whenever the tree cannot be trusted; the refresh pass and the update path read that inventory live through one injectable seam.
