## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| receipt -> removal argv | the package removed comes from the receipt and the registry |
| bun tree -> removal verdict | file presence decides "removed" versus "kept" |
| Doctor -> browser launch | the audit starts a real browser through puppeteer |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-24.5-17 | Denial of Service | removing another manager's copy | high | mitigate | the bun argv exists only for a receipt of kind bun naming the tool's declared package (`uninstall._manager_argv`); other owners get a hint, never a command |
| T-24.5-18 | Repudiation | false "removed" when bun keeps a peer | high | mitigate | the post-command tree check returns not-removed with the receipt kept (`test_bun_kept_peer_is_not_reported_removed`); the shortcut consults the tree too |
| T-24.5-19 | Elevation of Privilege | bare `bun` in the removal | medium | mitigate | `resolve_bun()` absolute path or a refusal; never the bare name |
| T-24.5-20 | Tampering | `bun_keeps` path join | medium | mitigate | a package name that is not a full `NPM_PACKAGE_RE` match never reaches the join and counts as kept |
| T-24.5-SC | Tampering | npm installs | high | accept | no dependency added; nothing installed |
</threat_model>
