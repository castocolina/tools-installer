<objective>
Make pressing enter on a selected, already-installed tool do something honest (D-17). Re-apply its
post-install actions only on that explicit selection (D-20), and repair a broken tool (D-18).

Purpose: CONTEXT.md defect 5. Selecting wezterm while it is current yields "Install 0 tools" and
nothing. ExecuteScreen already routes OUTDATED selections to updates (`_update_targets`) but drops
current ones silently. `post_install` is reachable only on a fresh install by design
(post_install.py docstring). D-20 widens that by exactly one case: fresh explicit selection. The
broken state from plan 16-09 needs a route into the install ladder past `ALREADY_INSTALLED`.

Output:
- `_current`/`_repair` classification and the preflight/progress text.
- `_with_repair`.
- `engine.reapply_post_install` dispatched for explicit installed selections.
- Updated docstrings in post_install.py and engine.py.

Output harness note: if `uv run pytest` prints a false "No tests collected", re-run via `.venv/bin/pytest`.
</objective>
