### Task 1: End-to-end "the container's rc files are self-deduping too"

**Objective:** Convert the two plain PATH exports in `write_tester_path()` to guarded forms through quoted heredocs, and prove runtime idempotency by executing the committed script's own bytes in real shells.

**Completed:**

- Replaced lines 152 and 158 in `scripts/container-e2e-verify.sh` (the `printf "%s\n" "export PATH=..."` appends to `~/.bash_profile` and `~/.bashrc`) with `cat >> ... <<"TI_PATH_GUARD"` here-documents.
- Guard line uses the exact structure from `installer/shellrc.py::path_export_guard`:
  - Case-guarded self-deduping idiom
  - Default-applying expansion `${PATH-}` so lines do not abort under `set -u`
  - Conditional expansion `${PATH:+:$PATH}` so empty starting PATH has no empty component
  - Double-quoted heredoc delimiter (`<<"TI_PATH_GUARD"`) so the payload is literal in a host-side single-quoted string
- Added a two-sentence comment explaining the distinction: these rc files are sourced by nested shells (so the export must be self-deduping), while the two `export PATH=` lines in `sync_workspace` and `run_setup_as_tester` (lines 186, 247) are one-shot command prefixes that remain unchanged.
- Grep guards (`if ! grep -q ".local/bin" ...`) are unchanged and continue to make the FILE idempotent.

**Tests (all passing):**

- `test_the_container_rc_append_is_runtime_idempotent`: Extracts the guard line from the committed script (never re-typed), runs the payload three times against a `tmp_path` HOME, asserts each file contains exactly one `.local/bin` line. Sources each file five times in bash and asserts exactly one copy of the directory on PATH.
- `test_the_container_rc_append_is_idempotent_under_zsh`: Same proof under zsh (with `-f` to skip user rc).
- `test_the_container_rc_append_is_idempotent_under_sh`: Same proof under `/bin/sh` (POSIX-DIALECT coverage; on this host, `/bin/sh` is bash invoked as sh).
- `test_the_container_guard_and_the_python_emitter_share_one_shape`: Asserts the shell guard and `path_export_guard(Path("/a/bin"))` both start with `case`, read PATH via `${PATH-}`, and use `${PATH:+:` conditional expansion.

### Task 2: The shell-side invariant — scan every shell script, classify one-shot exports

**Objective:** Implement a repo-level scan matching plan 15.8-03's Python expansion coverage so shell scripts cannot reintroduce the accumulating PATH prepend unseen. Classify the three surviving one-shot exports by stated property.

**Completed:**

- `_accumulating_shell_hits(files: list[Path]) -> list[Hit]`: Line scan (not parse) covering `install.sh` and every `*.sh` under `scripts/` recursively. Matches assignment to PATH (optional `export`, not preceded by word character so `MANPATH=` and `MYPATH=` are skipped) whose value references PATH through any expansion form from plan 15.8-03's needle:
  - Bare: `$PATH`
  - Braced operators: `${PATH-}`, `${PATH:-}`, `${PATH+}`, `${PATH:+}`, `${PATH=}`, `${PATH:=}`, `${PATH?}`, `${PATH:?}`, `${PATH#...}`, `${PATH##...}`, `${PATH%...}`, `${PATH%%...}`
  - Skips lines starting with `#` (commented) or `case` (guarded; mirrors `installer/rcclean.py:16`'s anchor)
  - Skips paths containing `.venv`, `.git`, `.worktrees`, or `.superpowers` as a path component

- `test_no_unclassified_accumulating_path_line_in_any_shell_script`: Scans the repo, asserts every hit is in the CLASSIFIED set and vice versa (equality in both directions). Classified entries:
  - `install.sh:60` — sets PATH for the remainder of its own bootstrap process and is never sourced
  - `scripts/container-e2e-verify.sh:186` — one-shot command prefix inside `su -c`; executes once in a fresh process and is never sourced
  - `scripts/container-e2e-verify.sh:247` — one-shot command prefix inside `su -c`; executes once in a fresh process and is never sourced
  - Each entry carries its reason (property) rather than restating the line, and the equality assertion forces the table to track reality rather than rotting into a permanent exemption.
