# Phase 15.8 — orchestrator review lane

This lane is empirical rather than read-only: every claim below was produced by
running the real code against real shells (`bash`, `zsh`, `/bin/sh`) on
fabricated `HOME` directories under `tmp_path`. No real dotfile was touched.

## CRITICAL-01 — reserved-word-prefixed source lines were missed (FIXED, `d298026`)

**`installer/shellrc.py:293`** — `_COMMAND_PREFIXES` omitted shell reserved words
and precommand modifiers.

`time` is a shell KEYWORD, not an external binary, so `time . file` really
sources the file. Verified executing under bash, zsh AND `/bin/sh`. The
classifier answered `none`, which is the loop-producing direction:
`consolidation_refusal` saw nothing to refuse, `consolidated_body` had no
rewritable verdict to act on, and the line was copied forward verbatim into
`~/.myshellrc`.

**Reproduced end to end before fixing.** A `~/.shellrc` containing
`time . "$HOME/.myshellrc"`:

    consolidation status: consolidated     <- reported SUCCESS
    line copied into ~/.myshellrc: time . "$HOME/.myshellrc"
    sourcing the stub -> returncode: -11   <- SIGSEGV

That is bash dying of stack exhaustion on every shell startup — the exact
failure the phase exists to prevent, delivered by a "successful" run.

zsh's `nocorrect` and `noglob` precommand modifiers have the same property and
were closed with it. An escaped `\time` is deliberately NOT listed: it resolves
to the external binary, which cannot source into the parent shell.

**Why three rounds of cross-AI plan review missed it:** those rounds swept
wrappers (`command`, `builtin`), escapes (`sour\ce`), quoting, and dynamic
command words. Reserved words are a fourth category nobody enumerated. The
lesson for later phases is that this detector's risk is categorical — the fix is
to enumerate the shell's grammar of "things that may precede a command", not to
add shapes one at a time as they are noticed.

Fixed with both halves pinned: each form is proven to really source the file in
the shells that have the word, and proven to refuse consolidation byte-for-byte
with no backup left. A mirror test pins `time make build` as still invisible, so
timing a build does not refuse consolidation.

## Verified sound — no finding

Everything below was attacked and held. Recorded so a later phase does not
re-litigate it.

**Classifier coverage.** ~76 line shapes classified and then actually executed in
bash, zsh and `/bin/sh`. After CRITICAL-01, **zero** shapes that a real shell
sources at startup are classified `none`. Covered: wrappers, escapes, quoted and
dynamic command words, split-quoted `. "$HOME"/.myshellrc`, aliased
symlinked-home spellings, compound/reserved-word/negated/assignment-prefixed
forms, `for`/`while` bodies, function bodies, process substitution, command
substitution, trailing arguments, and trailing separators.

`alias` and `trap` bodies classify as `none` and do NOT execute at startup —
they are deferred to user or signal invocation, so copying them forward verbatim
is correct, not a miss.

**Over-refusal.** 12 ordinary rc lines stay `none`. The single non-`none` verdict
is `source "$ZDOTDIR/foo"`, which is the documented unresolvable-argument
refusal, not a false positive.

**`sources_file`'s third answer.** Exactly one caller (`installer/app.py:241`).
Only `yes` skips the ordinary route; `unprovable` prints a diagnostic and falls
through to `ensure_source`. Never folded into `yes`.

**Backup validation.** Four attacks, all refused with the original byte-identical
and no backup created: a symlink at the backup path pointing at the original
(byte-equal, would have self-destructed once the stub was written), a
byte-identical backup with different mode bits, a directory, and a FIFO — the
last being one a naive `read_bytes()` would have blocked on forever. The
implementation uses `lstat`, `S_ISREG`, and `O_NOFOLLOW`, matching what
`.claude/architecture.md` claims.

**Concurrency window.** An edit landing between the snapshot read and the
replacement is detected: the operation refuses, `~/.myshellrc` is rolled back to
its exact original bytes, no backup is left behind, and the user's mid-flight
edit survives untouched.

**Single-route rule.** Load-bearing, proven by breaking it: forcing
`sources_file` to `no` makes the copied content execute **twice** per startup
(`__SHELLRC_RUNS = 2`) while the committed test asserts 1. The managed directory
stays on PATH exactly once even then — plan 15.8-01's guard — which is the
division of labour the phase documents: the guard protects OUR block, the
single-route rule protects the USER's content.

**Refusal surfacing.** Load-bearing, proven by breaking it: removing
`ShellrcRefusal` from `run_live`'s except tuple makes the wizard test fail with
an uncaught exception rather than pass quietly.

**Home-safety guard.** Load-bearing, proven by pointing its fingerprint at a
scratch directory: it detects a dotfile mutation, a newly created `~/.shellrc`,
and a backup sibling appearing while every dotfile is otherwise unchanged.

## Findings carried in from the implementation pass

Both were found and fixed before their commits landed; recorded here so the
review record is complete.

**`assert` used for control flow in production** (`installer/app.py`). The only
two asserts in `installer/`. Bandit rates B101 Low and **exits 0**, so
`make validate` does not catch them; under `python -O` they vanish and a refusal
would `console.print(None)`. Removed.

**A refusal message that claimed a write had happened before it had.** Printed
before `write_myshellrc`, so an exception in between would have reported a write
that never occurred. Moved after the writes.

**A pre-existing gate bypass** — `# pyright: ignore[reportUnusedFunction]` on
`_source_n_times`, committed in plan 15.8-01 and green through four plans.
Retired in 15.8-05 by making the helper used. Worth stating as a general lesson:
`make validate` cannot flag a suppression that was committed together with the
code it silences.
