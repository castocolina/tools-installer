**Files**: `installer/shellrc.py`, `tests/test_shellrc.py`

#### Implementation
- Added `path_export_guard(directory: Path) -> str` function that emits the case-guard idiom
  - Detects when directory has multiple spellings (e.g., /home -> /var/home on this host)
  - Guard matches both spellings while assignment emits only the declared one
  - Uses `${PATH-}` default-applying expansion for `set -u` safety

- Rewired `managed_block()` to call `path_export_guard()` for each directory
  - Each directory emits one guard line, one per directory
  - No merging of patterns into single alternation (per-directory attribution preserved)
