## Findings the orchestrator independently verified before acting

Not taken on the reviewer's word — each reproduced on this host:

- **Trailing empty PATH component executes from the cwd.** `env PATH="/nonexistent:"
  /bin/bash -c 'hello.sh'` ran `./hello.sh` from the working directory. The plans had
  mandated `"$directory:$PATH"` and told tests to treat the empty segment as harmless.
  Now `"{dir}${PATH:+:$PATH}"`, re-verified: empty PATH yields exactly the managed dir,
  no cwd resolution, and no abort under `set -u` with PATH unset.
- **`atomic_write_text` follows symlinks** (`installer/atomic.py:42`:
  `target = path.resolve() if path.is_symlink() else path`). With
  `~/.shellrc -> ~/.myshellrc`, consolidation would have written the stub INTO
  `~/.myshellrc`, destroying the canonical file and leaving it sourcing itself.
- **The repo already ships this defect elsewhere.** `scripts/container-e2e-verify.sh:152,158`
  append a plain `export PATH="$HOME/.local/bin:$PATH"`; the surrounding `grep` makes
  the file idempotent but re-sourcing still accumulates. Outside the original scan
  scope — now owned by the new plan 15.8-07.
- **This host's HOME is symlinked** (`HOME=/home/bazzite`, `/home -> /var/home`), so
  `/home/bazzite/.local/bin` and `/var/home/bazzite/.local/bin` are the same directory
  under different spellings; a literal string guard would prepend a second copy.
  Latent here (PATH currently uses one spelling consistently), but real.
- **Wrapped and escaped source forms execute**: `command source f.sh`,
  `builtin source f.sh` and `sour\ce f.sh` all ran the file under bash. They have
  statically resolvable arguments, so no blanket refusal caught them — they would have
  been copied forward and made `~/.myshellrc` source itself.

## Accepted and deferred

**Cycle 3 MEDIUM-03** — the repo-invariant AST scan cannot reconstruct fragments
defined in reverse dependency order, or a formatted assignment name such as
`f'export {name}="/x:$PATH"'`. Deferred: the invariant is defence in depth, not the
phase's guarantee. The guarantees are the emitter itself plus the real-shell
repeated-source tests in 15.8-01 and 15.8-07, which observe runtime behavior rather
than source shape — and those still catch a deliberately obfuscated reintroduction.
Closing the gap needs recursive constant resolution and dependency-ordered
reconstruction, i.e. a meaningful slice of a Python dataflow analyzer. The cheap half
WAS taken: the expansion needle now matches any braced expansion beginning with the
exact identifier `PATH`, which covers `${PATH//old/new}`.
