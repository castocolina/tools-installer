- **CLI test assertion wording.** The plan's `test_cli_doctor_reports_a_broken_bun_owned_puppeteer` expects `bun's copy`, but review cycle 3 (R3-03) renamed the prefix to `bun audit: `. The test asserts `bun audit: puppeteer could not start a browser: no browser` (whitespace-normalised against rich wrapping). No behaviour differs from the plan's binding text.
