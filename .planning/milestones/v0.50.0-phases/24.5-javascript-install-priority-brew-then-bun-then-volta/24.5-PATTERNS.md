### `installer/bun_globals.py` (NEW; utility, file-I/O)

**Analog:** `installer/pnpm_globals.py`. Its shape: pure `parse_global_packages(raw) -> tuple | None` plus a thin IO wrapper `pnpm_global_packages(...)` that returns `None` for "could not ask" (`:367-381`, `:482-503`):
```python
def pnpm_global_packages(*, resolve_pnpm=real_pnpm, runner_out=_run_list) -> tuple[str, ...] | None:
    """... None means "unknown", not "empty"."""
    pnpm = resolve_pnpm()
    if pnpm is None:
        return None
    try:
        raw = runner_out([pnpm, "list", "-g", "--json"])
    except (OSError, CommandError):
        return None
    return parse_global_packages(raw)
```
For bun there is no CLI. The reader instead:
- takes `<global tree>/package.json` `dependencies` as the keys;
- takes each version from `node_modules/<name>/package.json`;
- returns `{}` for a missing tree and `None` for an invalid or unreadable manifest;
- also carries the manifest range, because D-13's exact-pin refusal needs it (RESEARCH "Exact pin").

`bun_dirs()` returns `(bin_dir, global_tree)` per D-07 (env `BUN_INSTALL_BIN`, then `$BUN_INSTALL/bin`, then `~/.bun/bin`; and the same for the global tree). Add a `# shortcut:` comment that bunfig is not read. This module must import nothing from `ownership`, because `status.py` imports it and `ownership` imports `status` (`ownership.py:76`).

## Shared Patterns

### Fail closed on unreadable inventory
**Source:** `installer/ownership.py:386-392` (docstring), `_unreadable` `:1185-1198`. An inventory of `None` means "could not ask", never empty. Apply to `bun_globals`, `version_status` and `app.remove_tool`.

### Manager kind is a row in each table
**Source:** `model.py:109-119`, `executors.py:684-691`, `ownership.py:149-157`, `uninstall.py:111-116`. Add `bun` to each. The hint, the label and the removal command are generated from the argv table.

### Absolute-path manager invocation through the injected runner
**Source:** `executors._node` (`real_pnpm()`, `runner([...])`), `app.remove_tool` `:800-807`, `update._perform` `:387-390`. Never call `subprocess` directly; use `installer.run`.

- `tests/test_registry.py:2059` (`test_shipped_node_tools_require_pnpm`) contradicts D-19. Rewrite it in the same commit as the registry edit.
- Never write the quoted `"bun"` inside `catalog_tui._detail_text` or `_health_block` (`tests/test_catalog_tui.py:1995-2003`).
- The `_RANK` change rewrites about 45 existing tests, listed in RESEARCH "Tests that hard-code the old order". Land it last, or together with the golden table.
- `app.perform` in CONTEXT is `app.remove_tool` (`app.py:745`).
