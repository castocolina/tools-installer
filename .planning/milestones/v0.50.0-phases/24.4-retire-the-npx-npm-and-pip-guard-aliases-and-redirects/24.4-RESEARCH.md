### Primitive semantics (all `[VERIFIED: ... read this session]`)
- `strip_block` pairs the LAST begin marker with the first end marker after it and returns `content` unchanged when the last begin has no end. Lines are compared with `line == begin` after `content.split("\n")` (`installer/shellrc.py:175-188`: `start = max(index for index, line in enumerate(lines) if line == begin)`, `if lines[stop] == end:`). Consequences: (a) an orphan begin that sits AFTER a well-formed block hides the earlier block (the loop in D-07 ends with the earlier block still present, file byte-identical, which is acceptable and matches "orphan stays"); (b) a file that was converted wholesale to CRLF has markers ending in `\r`, so they never match and nothing is removed (same as today's `rewrite_outdated_ban_aliases`, which skips when `BAN_BEGIN not in lines`); (c) a mixed file whose marker lines are LF-terminated keeps every other `\r\n` because the text is decoded from raw bytes, not through universal newlines (D-05).
- `read_capped` opens `O_RDONLY | O_NONBLOCK | O_CLOEXEC`, adds `O_NOFOLLOW` unless `follow_symlinks=True`, checks type and size on the opened fd, returns `None` when not a regular file or over the cap, and lets `OSError` from the open propagate (`installer/atomic.py` docstring of `read_capped`).
- `read_snapshot` opens `O_RDONLY | O_NONBLOCK | O_NOFOLLOW`, raises `OSError("not a regular file of at most 16 MiB")` for a FIFO, device or oversize file, returns `FileSnapshot(data, device, inode, mode)` (`installer/atomic.py:89-112`). **It reads the whole file up to 16 MiB before D-08's 8192 check**, so pre-check `st_size` from the `lstat` you already do and skip anything above 8192 (cheap; the post-read length check stays for the race).
- `snapshot_matches` re-reads and compares device, inode and bytes; any `OSError` returns `False` ("an unanswerable comparison is a refusal") (`installer/atomic.py:115-127`).
- `atomic_write_bytes` resolves a symlinked path and replaces the target; copies the existing mode when `mode is None`; cleans its temp on `OSError` (`installer/atomic.py:38-60`). A failed write leaves the rc byte-identical (existing test `tests/test_guards.py:195` relies on that).
- Residual race, unavoidable with stdlib: between `snapshot_matches` and `os.unlink` a swap can still win. The identity check shrinks the window; do not claim it is closed. Document in a `shortcut:` comment.

### Remover design (D-04..D-08)

Two functions in `legacy_guard.py` (discretion: one function or two), composed in `_launch_repairs`:

```python
# Source: composed from the primitives verified above; names and wording are placeholders (discretion).
# Imports: os, stat, Path, installer.locations, atomic.{atomic_write_text, read_capped, read_snapshot, snapshot_matches},
#          sanitize.sanitize_log_line, shellrc.strip_block
GUARD_NAMES: tuple[str, ...] = ("npm", "npx", "pnpm", "pip", "pip3")

def _first_line(exc: OSError) -> str:
    return sanitize_log_line(((exc.strerror or str(exc)).splitlines() or [""])[0])

def remove_ban_blocks(rc_paths: Sequence[Path]) -> tuple[tuple[str, str], ...]:
    results = []
    for rc_path in rc_paths:
        try:
            data = read_capped(rc_path, _RC_MAX_BYTES, follow_symlinks=True)   # symlinked dotfiles stay readable
            if data is None:
                continue
            text = data.decode("utf-8")                                        # strict
        except (OSError, UnicodeDecodeError):
            continue                                                           # silent, as the current rewrite does
        stripped = text
        while (nxt := strip_block(stripped, BAN_BEGIN, BAN_END)) != stripped:  # D-07, terminates: text shrinks
            stripped = nxt
        if stripped == text:
            continue
        shown = sanitize_log_line(installer.locations.display_path(rc_path))
        try:
            atomic_write_text(rc_path, stripped)
        except OSError as exc:
            results.append((f"Could not remove the retired guard alias block from {shown}: "
                            f"{_first_line(exc)}; fix its permissions, then relaunch.", "warn"))
            continue
        results.append((f"Removed the retired guard alias block from {shown}.", "ok"))
    return tuple(results)

def remove_guard_shims(bin_dir: Path) -> tuple[tuple[str, str], ...]:
    results = []
    for name in GUARD_NAMES:
        path = bin_dir / name
        try:
            st = os.lstat(path)                       # never follows: a volta npx symlink is skipped
        except OSError:
            continue                                  # missing or unreadable parent: silent
        if not stat.S_ISREG(st.st_mode) or st.st_size > _SHIM_MAX_BYTES:
            continue                                  # also avoids reading up to 16 MiB in read_snapshot
        try:
            snap = read_snapshot(path)                # O_NOFOLLOW|O_NONBLOCK, refuses FIFOs
            if len(snap.data) > _SHIM_MAX_BYTES:
                continue
            text = snap.data.decode("utf-8")
        except (OSError, UnicodeDecodeError):
            continue
        if SHIM_SENTINEL not in text and REDIRECT_SENTINEL not in text:
            continue
        if not snapshot_matches(path, snap):          # swapped since the read: not ours any more
            continue
        shown = sanitize_log_line(installer.locations.display_path(path))
        try:
            os.unlink(path)
        except FileNotFoundError:
            continue                                  # a concurrent launch won: silent
        except OSError as exc:
            results.append((f"Could not remove the retired pip/npm guard shim {shown}: "
                            f"{_first_line(exc)}; delete it yourself or fix the bin dir permissions.", "warn"))
            continue
        results.append((f"Removed the retired pip/npm guard shim {shown}.", "ok"))
    return tuple(results)
```

Notes for the planner:
- Wire it so the whole `_launch_repairs` second element never raises: both functions catch what they touch; `os.lstat` of a path under a missing bin dir raises `FileNotFoundError` (an `OSError`), handled.
- For tests to hit the swap race (GUARD-03), `snapshot_matches` must be a module-level name in `legacy_guard` (import it with `from installer.atomic import ... snapshot_matches`) so a test can `monkeypatch.setattr(legacy_guard, "snapshot_matches", swap_then_original)`; this mirrors `tests/test_guards.py:339-361`, which swaps the file then calls the original.
- Read-only dir tests use `locked.chmod(0o555)` in a `try/finally` (precedent `tests/test_guards.py:279-296,428-443`); they assume the suite does not run as root, same as the existing tests.
- Message wording is free but the SPEC grep and the acceptance say "names the path" (display path through `sanitize_log_line(display_path(...))`).
- Add a `shortcut:` comment for the unlink race window (ponytail convention).

### Anti-Patterns to Avoid
- **Reusing `is_our_shim` for deletion:** it passes `follow_symlinks=True` (`guards.py:356`), so a volta `npx` symlink to a marked file would be deleted (violates GUARD-03).
- **Reusing `remove_ban_aliases`:** `Path.read_text()` universal newlines drops `\r`, and `UnicodeDecodeError` escapes (D-05).
- **Raising out of `_launch_repairs`:** every route prints lines from it; one exception aborts the launch.
- **Adding a replacement nudge** (alias, hook, Doctor hint, Policies knob): SPEC prohibition, judged in review.
- **Leaving `_RELOAD_HINT`, `_RC_PATHS` kwargs, `which` param etc. as dead code:** vulture@80 fails on unused params, grep catches the rest.

## Don't Hand-Roll

| Problem | Don't Build | Use Instead | Why |
|---------|-------------|-------------|-----|
| Block removal | a regex or a line loop | `shellrc.strip_block` in a fixpoint loop | already pairs last-begin, leaves orphans |
| Safe bounded read | `open().read()` | `read_capped` / `read_snapshot` | FIFO-safe, O_NOFOLLOW, size checks |
| Atomic rewrite | `write_text` | `atomic_write_text` | keeps mode, resolves symlinked rc, cleans temp |

### Applicable ASVS Categories
| ASVS Category | Applies | Standard Control |
|---------------|---------|-----------------|

### Known Threat Patterns
| Pattern | STRIDE | Standard Mitigation |
|---------|--------|---------------------|
| Symlink at a guarded name tricks the delete into removing another file | Tampering | `lstat` + `S_ISREG` (never follow), `read_snapshot` uses `O_NOFOLLOW` |
| TOCTOU swap between read and unlink | Tampering | `snapshot_matches` (device, inode, bytes); residual window documented, unavoidable with stdlib |
| FIFO/device named `npm` stalls the launch | DoS | `O_NONBLOCK` + type check in `read_snapshot`/`read_capped` |
| 150 MB file named `pnpm` read into memory | DoS | `st_size` pre-check before `read_snapshot` |
| Hostile path/strerror injects terminal control sequences into notices | Tampering/Spoofing | `sanitize_log_line` |
| Remover deletes a user's own alias | Tampering | marker-delimited block only, `strip_block` last-begin pairing, orphan left alone |
