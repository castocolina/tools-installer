### `installer/legacy_guard.py` rc removal (D-05, D-07)

**Analog:** `guards.py::rewrite_outdated_ban_aliases` (672-719) for the read; `shellrc.strip_block` (175-188) for the strip.

Read (C-11, byte-faithful; copy, then replace the rewrite part):
```python
_RC_MAX_BYTES = 1 << 20
try:
    data = read_capped(rc_path, _RC_MAX_BYTES, follow_symlinks=True)
    if data is None:
        continue
    text = data.decode("utf-8")
except (OSError, UnicodeDecodeError):
    continue            # silent skip, as today
```
Strip: `strip_block(content, begin, end)` removes only the LAST well-formed pair and leaves an orphan begin. D-07 needs a loop until the text stops changing:
```python
stripped = text
while (nxt := strip_block(stripped, BAN_BEGIN, BAN_END)) != stripped:
    stripped = nxt
if stripped != text:
    atomic_write_text(rc_path, stripped)   # only when changed
```
Warn line copy (guards.py 706-718):
```python
shown = sanitize_log_line(installer.locations.display_path(rc_path))
except OSError as exc:
    first = sanitize_log_line(((exc.strerror or str(exc)).splitlines() or [""])[0])
    results.append((f"Could not ... {shown}: {first}; fix its permissions, then relaunch.", "warn"))
```
Return type `tuple[tuple[str, str], ...]`. Do NOT use `remove_ban_aliases` (guards.py 659, uses `read_text`, drops `\r`, raises).
Never-raise precedent: `tweaks.strip_legacy_aliases` (tweaks.py 354-386) catches `FileNotFoundError`, `UnicodeDecodeError`, `OSError` separately and returns a `LegacyStrip`. Per D-04 keep the `tuple[LegacyStrip, tuple[tuple[str,str], ...]]` return of `_launch_repairs`, so the remover only feeds the second element.

### `installer/legacy_guard.py` shim removal (D-08)

**Analog:** `guards.py::rewrite_outdated_npx` (722-763). Replace the rewrite with `os.unlink`; loop over the five names.
```python
path = shim_dir / name
try:
    if not stat.S_ISREG(os.lstat(path).st_mode):   # lstat, never follows symlinks
        return ()
    snapshot = read_snapshot(path)                 # O_NOFOLLOW|O_NONBLOCK
    data = snapshot.data
    old = None if len(data) > _SHIM_MAX_BYTES else data.decode("utf-8")
except (OSError, UnicodeDecodeError):
    return ()
if old is None or not (SHIM_SENTINEL in old or REDIRECT_SENTINEL in old):
    return ()
if not snapshot_matches(path, snapshot):           # identity re-check before the destructive step
    return ()
os.unlink(path)   # FileNotFoundError silent; other OSError -> one warn line naming path + fix
```
Differences to implement: `lstat` miss (`FileNotFoundError`) is silent; the exact-8192-byte file is removed and 8193 stays (`len(data) > _SHIM_MAX_BYTES`); a zero-byte file has no sentinel so it stays. Never call `is_our_shim` here (follows symlinks).

## Shared Patterns
- **Never raise at launch:** return `(text, "ok"|"warn")` tuples; `OSError` becomes a warn line with the `strerror` first line through `sanitize_log_line`.
- **Paths shown:** `sanitize_log_line(installer.locations.display_path(p))`.
- **Atomic write only when changed:** `atomic_write_text(path, text)`.
- **Identity gate before a destructive step:** `read_snapshot` then `snapshot_matches`.
- **Tests:** scratch HOME; conftest real-HOME fingerprint; no renderer helpers in fixtures.
- **Vulture:** run `uv run vulture --min-confidence 60` over touched modules (D-12).
